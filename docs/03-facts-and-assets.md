# 사실 기준과 원본 자료 수집

> 이 문서에서 해야 할 일: 사용자 브리프의 사실을 대본·장표에서 같은 의미로 사용하고, 각 장면을 뒷받침할 내부 원본을 수집한다. 최종 촬영 전에 아래 확인 목록의 명칭·개최 여부·참여 범위를 검토한다.

**작성 기준일:** 2026-10-09 / **입력:** 교육담당이 제공한 프로젝트 브리프 및 추가 확인 답변.

**확인 수준:** 아래 팀 활동은 사용자 제공 사실이다. 행사 증빙, 참석 기록, 실제 화면을 독립적으로 대조한 상태는 아니다. `브리프 기준 사용`은 초안에 활용할 수 있다는 뜻이며, 공식 실적 검증 완료를 뜻하지 않는다. 웹 자료는 기술 배경·시각 참고로 별도 관리한다.

## 7. 초안의 근거 한계

6개 프로젝트·44명·25명·11개 부서·8명은 **교류와 실행의 규모**를 설명한다. 운영 효율이 얼마나 개선됐는지, 학습 효과가 얼마나 높아졌는지를 증명하는 지표는 아니다. 이 영상에서 말할 수 있는 성과는 부서의 경계를 넘는 참여, IAP의 팀 미션 확장·운영 도입과 로그 패턴 감지·메신저 동보의 수작업 대체, 소개와 실습, 현장 체험, 녹화 공유라는 제공된 사실이다. 수작업 대체는 사용자 확인에 따른 정성적 실질 성과이며, 절감 시간 등 정량 성과는 아직 제공되지 않았다.

전체 스토리는 활동의 연결을 보여 주는 편집 구조다. AI 4 AI 세미나 → Job Fair → Tech X → IAP가 하나의 순차적 사업으로 추진됐거나, 앞 프로그램이 뒤 프로그램을 직접 발생시켰다고 해석하지 않는다.
