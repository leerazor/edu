## 문구와 촬영

타이틀은 **AI 4 AI — 함께 쌓는 전문성**이다. 화면은 프로그램명·짧은 제목·확인된 사실로 구성한다. 이유와 경험은 출연자가 말한다. 리디자인할 때 설명문을 다시 큰 제목으로 늘리지 않는다.

팀장은 DS부문 인프라 책임과 AI를 활용하는 운영을 소개한다. 교육담당의 “외부 전문가에게 기술을 배우고”에서 P01을 띄운다. 도입에서 팀 역할과 교육문화의 핵심을 먼저 설명한 뒤 사례로 들어간다. 첫 개인 화면에는 이름·직함을 표시한다.

P06의 개인 GPU 과제 경험과 P07의 IAP는 서로 다른 과제다. IAP는 기능과 소개·실습을 합쳐 35초다. 결말은 기술과 동료의 경험을 나누며 AI 인프라를 다루는 전문성을 함께 키우겠다는 방향으로 마무리한다.

제목은 한 번에 띄우고, 짧은 디졸브로 전환한다. 사진·화면은 설명하는 부분만 확대한다. 단어마다 효과를 주거나 장표마다 별도 코너 오프닝을 넣지 않는다. PPT는 정적이며 효과는 영상팀 편집 지시다. 실제 낭독과 자료를 보는 시간은 리허설 CSV에 기록한다.

## 제출본 보존과 일정

실제 자료는 PPTX 사본에 넣는다. 예를 들어 `learning-fair-2026-editorial-v05-1014-submission.pptx`는 제출본 파일명 예시이며 현재 생성된 파일은 아니다. 자동 빌드는 기본 PPTX를 다시 쓰므로 삽입한 사본을 별도 보관한다. 사진 삽입 후 PDF도 다시 내보낸다. 현재 PDF·PNG·검증 보고서는 삽입 전 제작본 기준이다.

10월 11일 기준으로 OutSystems는 12일 예정, 자료 제출은 14일, Tech X 최종 발표는 16일 예정, 촬영은 19일이다. 제출본에 미확인 최종 발표·시상 결과를 넣지 않는다. 최종 발표일은 프로젝트 완료나 시상일로 확인된 날짜가 아니다. 이후 확인된 변경은 바뀐 장면·대사·자료를 묶어 영상팀에 전달한다.

## 재생성과 검증

```bash
.venv/bin/python scripts/build_editorial_v05_package.py
bash scripts/render_editorial_v05_slides.sh
.venv/bin/python scripts/validate_editorial_v05_package.py
```
