# 공동 해설 개정본 제작 기준

> 이 문서에서 해야 할 일: 새 대본과 화면을 아래 기준으로 만들고, 독립 검토에서 나온 지적을 수정한 뒤 실제 PowerPoint 화면과 발화량을 확인한다. 기존 기본본·월드컵본은 덮어쓰지 않는다.

작성일: 2026-10-11. 사용자는 형식을 계속 탐색하되 아이디어 전달에서 끝내지 말고, 비판적 리뷰와 실제 자료 개선까지 진행하도록 요청했다.

## 이번에 끝낼 작업

1. 기존 추천을 포함한 세 가지 도입·연결 방식을 실제 문장으로 비교한다.
2. 검토를 통과한 한 안을 `content/editorial-film.json`에 작성한다.
3. 이 원본에서 별도 PPTX·대본·콘티·프롬프터·발화량 보고서를 생성한다.
4. 독립 검토자가 말투·나열·과장·장면 연결을 지적하고, 채택·기각 이유와 수정 결과를 기록한다.
5. PowerPoint에서 PDF·PNG를 내보내 글자·배치·노트·자료 큐를 검증한다. 화면을 직접 보고 필요한 부분을 수정한다.
6. 이전 파일의 보존을 확인하고 새 산출물을 main에 커밋·푸시한다.

## 편집 기준

- 형식의 이름을 정하는 것보다 실제로 말할 문장을 먼저 쓴다.
- '연결·성장·확산·선순환'을 반복하는 대신 누가 무엇을 했는지 말한다.
- 질문이 다음 행사 이름을 호출하는 용도로만 쓰이면 삭제한다.
- 두 사람 모두 구체적인 활동과 자신의 해석을 말한다. 실제 참석·기억·직원 반응을 창작하지 않는다.
- IAP는 대표 사례 한 장면, 약 35초다. AI 4 AI의 외부 전문가 교류와 녹화 공유도 실제 내용으로 남긴다.
- 서로 다른 활동 사이의 실제 확인되지 않은 발생 순서·인과관계는 만들지 않는다.
- 새 기획은 편집 제안이다. 출연자의 생각을 인용한 기록이나 검증된 시청자 반응으로 부르지 않는다.

## 화면 기준

밝은 바탕, 짙은 글자, 한 가지 강조색을 사용한다. 반복되는 세 칸 카드, 추상적 아이콘, 네온 연결선, 장식용 AI 이미지는 쓰지 않는다. 한 장표에 한 가지 내용만 남기고 문장은 구체적으로 쓴다. 화면마다 같은 레이아웃을 복제하지 않는다.

내부 사진과 실제 행사 판넬·플랫폼 원본은 아직 없다. 사용자 확인 사실을 단순한 글자와 도식으로 설명하는 대체 화면을 만든다. 가상의 행사 사진·실제처럼 꾸민 판넬·가짜 플랫폼 화면으로 증거를 만들어내지 않는다. 원본 요청과 교체 위치는 노트와 제작 문서에 둔다.

PPTX는 정적 편집 원본이다. 필요한 등장·강조·전환은 대본의 정확한 발화 위치와 노트에 적어 영상팀이 구현하도록 한다. 원본 화면을 받기 전에도 검토할 수 있게 본편에 빈 사진 자리를 크게 남기지 않는다.

## 고정 조건과 저장 위치

총 300초: 회사 오프닝 5초, AI 팀 소개 15초, 본편 275초, 회사 클로징 5초. 출연자는 류경동 팀장·이관우 교육담당이다. 발화량은 발음 환산 추정이며 실측 리허설은 별도로 남긴다.

- 원본: `content/editorial-film.json`
- 새 문서: `docs/editorial/`
- 새 제작물: `deliverables/editorial/`
- 빌드·렌더·검증: `scripts/*editorial*`
- 사실 기준: [기존 사실·원본 목록](../03-facts-and-assets.md)
- 기존 추천: [유튜브 비교 후 판단](../17-format-decision.md)

현재 수치가 없는 절감 시간·만족도·참여 후기·외부 확산 실적은 넣지 않는다. 10월 세미나는 개최 확인 전까지 예정으로 유지한다. 새 대본은 출연자 검토와 리허설 전의 제작 초안이다.
