# 애니메이션·촬영 효과 검토

> 이 문서에서 해야 할 일: 효과가 어떤 내용을 이해시키는지 확인하고, 발화 큐·완성 화면·홀드·종료 상태를 기준으로 영상팀의 후반 편집 지시를 구체화한다. 시간은 해당 장면 안에 배정하고, 적용 후 합계 300초를 다시 확인한다.

**검토일:** 2026-10-10. 현재 PPTX의 실제 애니메이션은 없으며, 이 문서는 적용 전 제안이다. P번호와 시간은 **현재 v0.1**을 가리킨다. [추천 콘셉트](10-presenter-review.md)의 R01~R06을 채택하면 번호·큐·타임코드를 다시 배치해야 한다.

**디자인 비교 시안:** [사례별 검토와 추천안](12-design-concept-references.md)에 창 열기·두 관점의 공동 화면·기록 펼침의 세 방향을 비교했다. 본 문서의 교류 중심 원칙을 유지하는 자체 시안이며, 확정 편집 효과가 아니다.

## 1. 전체 판단

**효과의 중심은 서로의 일을 이해하고 함께 참여하는 모습이다.** ‘내가 맡은 일’ 옆으로 동료의 일이 보이고, 함께 해볼 과제와 참여자가 나란히 놓이는 정도로 교류를 표현한다. 실제 사진 속 대화·설명·현장 체험을 충분히 읽게 한다.

AI의 두 역할, IAP의 기능 순서, 다른 조직의 시작 방법에는 짧은 설명 효과를 쓸 수 있다. IAP만 가장 크고 화려하게 움직이면 분량을 줄여도 영상의 중심으로 보인다. **IAP 효과는 대표 사례 약 40초 안의 일부**로 사용하고, 오프닝·엔딩에는 교류의 질문과 사람을 남긴다.

현재 지시에는 AI 소개의 빛 이동, P01 점등, P02 양방향 선, P05 부서 연결, P09 회로 완성이 반복된다. 모든 구간에서 같은 빛이 이동하면 어디서나 볼 수 있는 AI 홍보 영상의 인상이 강해지고, 독립된 프로그램들이 서로를 발생시킨 것처럼 보일 수 있다. 사진 속의 사람과 실제 업무가 이 팀의 개성을 보여 주도록 한다.

## 2. 공통 모션 문법

| 사용할 효과 | 목적 | 제안 방식 |
| --- | --- | --- |
| 업무 카드의 나란한 등장 | 내가 아는 일 밖으로 관심과 경험이 넓어짐을 표현 | ‘내가 맡은 일’은 유지하고 ‘동료의 일’을 옆에 짧게 공개. 이후 실제 교류 사진으로 전환. 부서가 합쳐지거나 조직 경계가 사라진 것처럼 그리지 않음. |
| 고정 위치에서 현재 항목 강조 | 발화와 시선의 위치를 맞춤 | 위치는 유지하고 바탕의 강조만 한 번 이동. 이전 단계의 글자는 계속 보이게 함. |
| 단계별 공개·강조 | 확인된 기능의 순서 또는 제안을 설명 | 해당 단어가 나오는 순간 한 단계 전개. 세 단계가 완성되면 움직임을 멈춤. |
| 인물 ↔ 실제 자료의 컷 전환 | 말의 근거를 보여 주고 발표자에게 돌아옴 | 짧은 컷 또는 약 0.2~0.3초 전환. 사진은 의미를 읽는 동안 유지. |

수치는 0부터 세어 올라가지 않고 완성값으로 보여 준다. ‘44명’의 카운팅은 참여 효과나 증가 추세를 보여 주는 자료가 아니다. 큰 확대·회전·반복 펄스·글자 한 자씩 타이핑·매 장면 카메라 줌은 생략하는 편을 추천한다.

위 시간은 편집용 제안값이며 회사 규격이나 실측 처리 속도가 아니다. 음성·사진·자막을 넣은 상태에서 영상팀이 조정한다.

## 3. 현재 장표별 판단

| 자료 | 현재 지시에서 유지할 것 | 줄이거나 바꿀 것 |
| --- | --- | --- |
| P01 | 간단한 팀 소개와 첫 질문 | 세 개 키워드의 연속 팝업과 마지막 연결선 점등은 생략 가능. 추천안에서는 동료의 일에 대한 질문과 나란한 업무 카드로 교체. |
| P02 | 두 역할을 나란히 놓고 발화에 맞춰 강조 | 계속 왕복하는 빛을 쓰지 않음. 영문 확장명은 고정 보조 표기로 유지. |
| P03 | 실제 세미나 사진·대표 포스터, 월 1회 | 많은 포스터가 빠르게 지나가는 월별 몽타주와 로고 퍼레이드 생략. 대표 사진 한 장의 교류 장면이 읽히게 함. |
| P04 | 부스 사진에서 내부 공유 자료로 전환 | ‘매달 열리는 DCIS에서는’를 다음 사진 전환 큐로 명시. 사진 두 장을 읽기도 전에 교체하지 않음. |
| P05 | 6개 프로젝트·44명, 다른 부서의 일에 참여한다는 내용 | 여러 선이 얽히는 효과와 숫자 카운팅 생략. 참여자와 관심 과제의 간단한 배치로 참여 방식을 먼저 설명. 실제 부서·참여자 구성은 확인 전 임의로 채우지 않음. |
| P06 | 로그 감지→정형 메시지→동보의 확인된 순서 | 기능 도식은 해당 사례 안에서만 짧게 강조. 과제·미션·운영 정보와 확대 목표를 동시에 움직이지 않음. 개정안에서는 P07의 소개·실습까지 합쳐 약 40초로 배정. |
| P07 | 6월 소개, 7월 실습의 실제 자료 | 빠른 날짜 타이핑보다 두 장면의 목적 차이를 읽게 함. 25명을 25개 인물 아이콘으로 만들어 화면을 채우지 않음. |
| P08 | 실제 현장·사람의 사진 | 물·바람 파티클이나 합성 서버 소리로 체험을 대신하지 않음. 추천안 R03에서 숙련자와 신규·복귀 구성원이 현장을 경험하는 의미를 보여 줌. |
| P09 | 녹화 공유와 다른 조직의 시작 방법 | 4단계 문화 회로와 3단계 확산 제안을 모두 움직이지 않음. 마지막 제안 3단계를 선택. |
| P10 | 타이틀과 두 사람의 마지막 인사 | 긴 로고 조립·연결선 완성 효과를 추가하지 않음. 타이틀을 말하는 동안 안정적으로 유지. |

하단의 네 단계가 누적 점등되면 영상의 시간순·원인순으로 보일 수 있다. 필요하다면 **현재 이야기 단계만** 표시한다. P02의 화살표는 역할 관계, P06의 화살표는 실제 동작 순서, P09의 화살표는 제안의 순서로 각각 읽히게 한다.

## 4. 교류를 보여 주는 주된 효과

아래 R번호는 **개정 제안** 기준이다. 현재 P번호의 실제 큐는 정식 대본 개정 때 함께 교체한다.

### R01 · 동료의 일이 보이다 · 제안 00:20~00:50

- **진입:** 두 사람 투샷으로 짧은 인사. ‘다른 부서’라는 말에 ‘내가 맡은 일 / 동료의 일’ 카드를 나란히 표시.
- **전개:** 두 카드 사이의 여백을 짧게 강조한 뒤 멈춤. 서로를 알아보는 기회를 나타내며 단절·갈등의 증거처럼 벽을 세우고 부수지 않음.
- **홀드·종료:** ‘서로의 일을 알아보고’부터 실제 Job Fair·DCIS 교류 사진 한 장으로 전환. 사진 미수급 시 카드 완성 화면 유지.
- **제약:** 특정 사람이 모든 행사에 참여한 것처럼 이어지는 가상 인물·캐릭터는 사용하지 않음.

### R03 · 업무·고민·현장을 만나다 · 제안 01:35~02:35

- **전개:** 부스의 업무 소개 → 정기적인 주요 업무·서비스·연구 공유 → 숙련자와의 현장 경험으로 발화의 초점을 바꿀 때 자료를 전환.
- **자료:** 각 장면에 실제 사진 한 장과 ‘서로의 업무 / 정기적인 공유 / 현장 경험’ 같은 짧은 설명을 둠. 프로그램 이름은 보조 표기.
- **홀드:** 세 자료를 한꺼번에 쌓지 않고 각 경험의 설명 동안 유지. 투어는 서버의 화려함보다 함께 보고 설명하는 사람이 드러나는 사진을 우선.
- **제약:** 순서는 편집상 묶음이다. 프로그램 사이에 발생 순서를 뜻하는 화살표를 붙이지 않음.

### R04 · 함께 해볼 기회 · 제안 02:35~03:45

- **전반 약 30초:** ‘다른 부서의 관심 있는 프로젝트’라는 발화에 참여자와 과제 카드를 나란히 보여 줌. ‘6개 프로젝트 / 44명’은 고정 보조 정보. 실제 사진이 확보되면 공동 참여 장면으로 교체.
- **대표 사례 약 40초:** IAP의 과제·미션 확장, 실제 알림 기능, 팀 소개·실습을 한 번에 마침. 기능 단계 강조는 이 구간의 일부이며 나머지는 참여와 공유를 보여 주는 자료에 배분.
- **종료:** 알림 도식에서 실무자에게 활용 방법을 나누는 장면으로 옮긴 뒤, R05에서는 녹화·플랫폼 공유와 다른 조직의 참여 기회로 넓힘. IAP 기능을 다시 재생하지 않음.

## 5. 설명을 돕는 보조 효과

아래 P번호·큐·시간은 **현재 v0.1을 검토한 기록**이다. 개정안 R번호의 적용 지시로 바로 사용하지 않는다. 특히 P06의 43초와 P07의 30초는 새 구성에서 통합·압축할 대상이다.

### P02 · AI의 두 방향 · 00:45~01:10

- **진입 큐:** ‘그 연결의 이름이’에서 두 역할 카드가 놓인 완성 화면으로 전환.
- **전개:** ‘AI를 위한 인프라’에서 첫 카드 강조. ‘AI로 인프라 운영을 발전시키는’에서 두 번째 카드 강조. 서로의 역할 관계를 나타내는 선은 한 번만 표시.
- **홀드:** ‘두 방향을 잇는 힘은’부터 두 카드가 함께 읽히는 상태 유지.
- **종료:** 다음 문장의 도입은 발표자에게 돌아와 전달. ‘삼월부터 매달’에서 P03 사진 등장.
- **정적 대체:** 두 카드와 양방향 관계가 이미 읽히므로 강조 이동 없이도 이해 가능.

### P06 · 알림 자동화 · 02:38~03:21

- **진입 큐:** ‘그중 한 프로젝트가’에서 IAP 이름과 과제·미션·도입 정보를 고정 표시.
- **핵심 큐:** ‘서버 로그에서 특정 패턴을 감지하면’부터 기능 도식이 화면의 중심이 됨.
- **전개:** 로그 패턴 감지 → 정해진 포맷 → 메신저 동보를 해당 발화에 맞춰 한 번씩 강조. 글자는 고정하고, 필요하면 하나의 작은 표식만 한 방향으로 이동.
- **홀드:** 완성된 기능 세 단계를 유지하며 수동 업무 대체를 설명. 실제 IMG08이 확보되면 **43초 안의 설명 발화와 겹쳐 약 5초** 교체. 도식이 기본안.
- **종료:** ‘AI를 위한 인프라를 제공하는 우리가’에서 팀장님의 화면으로 돌아와 의미를 회수.
- **확대 방향:** 팀 인프라 전반은 ‘목표’라는 표시를 붙여 고정. 전 영역이 차례로 켜지는 효과는 적용 완료처럼 보여 사용하지 않음.

**8초 동작 검토 예시**는 `deliverables/review/iap-motion-review.html`에 있다. 대표 사례 안의 보조 효과를 검토하는 자료이며 전체 영상의 콘셉트나 오프닝 예시가 아니다. 세 단계를 읽고 발화에 맞춰 강조하는 방식만 보여 준다. 실제 IAP 화면·처리 속도·완성 영상·PPTX 적용 효과가 아니며, 8초는 동작을 살펴보는 예시 시간이다. 자동 반복이나 음향은 없다. 재생·일시정지·시간 이동으로 확인하고, 동작 줄이기 설정에서는 정적 완성 상태를 사용한다.

### P09 · 다른 조직의 시작 방법 · 04:11~04:35

- **진입 큐:** ‘외부 세미나는 녹화해’에서 승인된 교육 플랫폼 화면 또는 공유 문구 표시.
- **전개 큐:** ‘교류를 열고 / 작은 공동 과제를 시작하고 / 결과를 다시 나누는’에 맞춰 제안 세 단계를 강조.
- **홀드:** ‘다른 조직에서도 시작할 수 있는’ 동안 완성 화면 유지. ‘다른 조직의 시작 제안’이라는 제목으로 실제 도입 실적과 구분.
- **종료:** P10의 첫 발화 큐에서 타이틀 전환. 별도의 엔딩 효과 시간을 추가하지 않음.
- **정적 대체:** 순서가 읽히는 세 문장만 고정해도 전달 가능.

## 6. 시간 배분에서 발견한 위험

기존 발화량 보고서의 **느린 속도·최소 호흡 가정**에서 아래 여유가 남는다. 실제 리허설 결과는 아니다.

| 장면 | 배정 | 느린 발화·기본 호흡 추정 | 추가 여유 |
| --- | ---: | ---: | ---: |
| S04 / P04 | 31초 | 30.33초 | 0.67초 |
| S06 / P06 | 43초 | 40.38초 | 2.62초 |
| S09 / P09 | 24초 | 23.19초 | 0.81초 |
| S10 / P10 | 20초 | 19.90초 | 0.10초 |

**사진 5초·타이틀 홀드를 발화 뒤에 더하면 장면이 넘칠 수 있다.** 현재 콘티의 ‘5초 삽입’도 다음 개정에서 ‘기존 설명 발화 위에 5초 겹쳐 사용’으로 표현을 통일한다. 전체 약 12초의 여유가 특정 장면에도 그대로 남는 것은 아니다.

발표자는 화면 효과를 기다리지 않는다. 자연스럽게 말하고, 편집자가 발화 큐에 자료를 붙인다. ‘이쪽을 봐 주세요’라고 몸을 돌리거나 손으로 정확한 화면 위치를 가리킬 필요도 없다. 대화의 방향과 시선만 리허설에서 정한다.

## 7. 15초 AI 소개와 연결

현재 15초는 시설·양방향 AI·사람 노드로 구성되어 있다. 팀의 역할을 짧게 읽히게 하고 본편의 동료와 배움에 대한 질문으로 넘기는 편을 추천한다.

- **00:05~00:10:** 팀 이름과 인프라 역할. 과장된 서버 통로 비행 대신 간단한 연산·인프라 형상.
- **00:10~00:15:** AI를 위한 인프라 제공 ↔ AI를 활용한 운영을 한 번 보여 줌.
- **00:15~00:20:** 타이틀을 안정시키고 **마지막 2초는 고정**. 사람 노드·빛 이동·긴 타이틀을 동시에 처리하지 않음.
- **현재 v0.1 연결:** 00:20 두 사람의 짧은 인사 → 실제 첫 자료 큐에서 P01. AI 마지막 화면과 P01을 곧바로 붙인다는 지시는 수정 필요.
- **추천안 연결:** 00:20 짧은 인사와 동료의 일에 대한 질문. 두 업무 카드는 새 오프닝 발화 큐에 맞춰 등장. 최종 타이틀을 바꿀 경우 AI 소개도 같은 명칭으로 갱신.

회사 인트로·AI 소개의 소리에서 발표 음성으로 자연스럽게 전환한다. 서버 경보음이나 메신저 효과음은 실제 사건처럼 오인되거나 발화를 가릴 수 있으므로 기본안에서는 넣지 않는다.

## 8. 영상팀에 줄 최소 전달 세트

1. 해당 장표의 **완성 정지 화면**: 애니메이션이 없어도 읽혀야 함.
2. **발화 큐**: 초 단위 자동 재생보다 실제 녹음 문장을 기준으로 함.
3. **강조 순서와 종료 상태**: 어느 항목이 강조되고, 언제 멈추는지.
4. **시간 포함 관계**: 효과와 사진 컷은 본편 장면 시간 안에서 음성과 겹쳐 사용.
5. **원본 위치**: 실제 사진·화면을 쓸 위치와 미수급 시 도식 대체.
