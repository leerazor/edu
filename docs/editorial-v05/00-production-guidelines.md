# v05 문구 교정 기준

> 이 문서에서 해야 할 일: 장표 제목·보조 문구·도표·자료 자리·대본을 아래 기준으로 함께 교정한다. 기존 v04는 보존하고 v05 원본에서 PPT·대본·콘티를 재생성한다.

## 화면 문구

- 부제는 **함께 쌓는 전문성**이다. 제목에 설명문이나 당위문을 넣지 않는다.
- 상단에는 프로그램명, 큰 제목에는 이번 장면의 내용, 작은 글자에는 확인된 사실을 쓴다. 같은 뜻을 세 위치에서 반복하지 않는다.
- ‘AI를 잘 지원하고 활용하려면’, ‘전문성을 교류하다’, ‘기술의 방향을 배우다’처럼 뜻이 모호하거나 입에 붙지 않는 표현을 고친다.
- 업무·과제·GPU·로그·알림·실습·녹화처럼 실제 자료로 보여줄 수 있는 단어를 우선한다.
- 문장 끝만 지워 명사형으로 만들지 않는다. 제목에 필요한 정보부터 골라 다시 쓴다.
- 160명 규모는 도입에서 강조하지 않는다. AI 4 AI의 공식 확장명은 유지한다.

## 촬영 대사

- 팀 역할과 교육문화의 핵심을 먼저 설명한다. AI 인프라와 AI를 활용하는 운영에는 새로운 기술과 다른 부서의 경험이 함께 필요하다는 관계를 자연스럽게 연결한다.
- 장표의 키워드를 문장으로 되읽지 않는다. 화면에 없는 이유·참여 방식·본인의 경험을 말한다.
- ‘기회를 열어둡니다’, ‘역량의 방향’, ‘과정 자체가 배움’ 같은 기획서 문장을 구체적인 행동으로 고친다.
- 팀장은 교육에 대한 생각과 실제 운영 내용을 말한다. 교육담당에게 답을 유도하는 질문이나 ‘그렇겠죠’ 같은 형식적 교대를 줄인다.
- IAP는 S07의 35초 대표 사례다. 개인 GPU 과제와 구분한다. GPU 효율 개선 수치나 새로운 에피소드는 만들지 않는다.

## 편집과 검수

P01–P10·S01–S10의 대응과 실제 자료 자리 9곳을 유지한다. 문구를 고치면 큐의 기준 문장과 노트·콘티·프롬프터도 맞춘다. 최종 배정은 300초이며 발화 추정과 실제 낭독을 구분한다.

10월 11일 기준 예정 행사와 제출·촬영 일정은 유지한다. 10/12 OutSystems, 10/14 자료 제출, 10/16 Tech X 최종 발표, 10/19 촬영이다. 날짜가 지났다는 이유로 완료형으로 바꾸지 않는다.
