## 2. 발화 추정의 해석

기준 속도에서는 본편 발화·최소 호흡이 242초이므로 약 33초를 자료·전환에 사용할 수 있다. 느린 속도에서는 약 12초가 남는다. 최종 영상 300초는 **편집 배정**이며 추정 읽기 시간과 다른 값이다. 영문·숫자 치환표는 `content/film.json`에서 확인한다.

실제 화자 속도·강조·긴 쉼·발화자 교대의 시간이 추정과 다를 수 있다. 리허설 실측은 아직 없고 `deliverables/rehearsal.csv`의 실측 칸은 비워 두었다. 실측 전 ‘정확히 5분으로 읽힌다’거나 실측 검수 완료라고 말하지 않는다.

## 3. 편집 검토에서 수정한 항목

1. 최초 IAP 소개에서 실제 기능이 없던 부분에 사용자 확인 사례를 추가하고 P06을 43초로 확대했다. 나머지 장면을 압축해 275초를 유지했다.
2. S01은 질문 이후에도 마지막 발화가 있으므로 P01을 유지하고, S02의 ‘그 연결의 이름이’ 큐에서 P02로 바꾸도록 수정했다.
3. 마지막 동시 발화는 문장 수가 아니라 ‘마지막 공동 발화 블록’으로 지시해 대본과 맞췄다.
4. 공개 외부 사진은 A03 참고 부록으로 제한하고 실제 행사 자료 번호와 구분했다.

## 4. 재검수 명령

저장소 루트에서 실행한다. Python 환경은 `README.md`의 설치 명령을 사용한다.

```bash
.venv/bin/python scripts/build_package.py
bash scripts/render_slides.sh
.venv/bin/python scripts/validate_package.py
```

두 번째 명령은 현재 WSL + Windows Microsoft PowerPoint 환경에서 실제 PPTX를 PDF·PNG로 렌더한다. 다른 환경에서는 PowerPoint에서 PDF 내보내기와 1600×900 PNG 13장을 같은 경로로 저장한 뒤 검수한다. 처음 생성한 PPTX에는 애니메이션이 없고, 문서의 효과는 영상팀 후반 편집 지시다.

## 5. 남은 제작 작업

- 교육담당·팀장님의 문장 검토와 장면별 리허설 실측.
- 실제 내부 행사·IAP·플랫폼·HPC센터 원본 수급 및 사용 범위 확인.
- 10월 세미나 개최 후 상태 갱신.
- 회사 KV·폰트·로고와 실제 5초 인트로/아웃트로 적용.
- AI 소개 영상 생성, 스튜디오 촬영, 전문 영상팀의 최종 편집·300초 확인.

이 단계들은 초안 납품 이후의 작업이다. 미제공 수치·실제 후기·회사 전 영역 적용을 임의로 채우지 않는다.

## 6. GitHub 납품 확인

PPTX·PDF·미리보기·전체 제작 문서·출처·재생성 스크립트를 포함한 43개 파일을 `https://github.com/leerazor/edu`의 `main`에 푸시했다. 최초 제작 패키지 커밋 `9fdbaaa`의 원격 SHA가 로컬과 일치하고 작업 트리가 clean임을 확인했다. 이 확인 상태를 문서에 반영한 후 문서 갱신 커밋도 같은 브랜치에 푸시한다. 가상환경과 인증정보는 포함하지 않았다.
