# 확인된 사실과 필요한 원본

> 이 문서에서 해야 할 일: 아래 확인 사실로 자료·대본을 작성하고, 실제 원본을 받으면 파일명·날짜·사용 범위를 기록한다. 현재 장면 번호는 balance-v03의 대본·콘티를 따른다. 예정·목표·개인 경험을 완료된 성과로 바꾸지 않는다.

**확인 기준: 2026-10-11 사용자 제공 내용.** 내부 통계와 운영 상태를 독립 검증한 자료는 아니다. 출연자는 **류경동 팀장 / 이관우 교육담당**이다.

## 팀 역할과 교육문화

- DS부문 임직원 **7만 명 이상**이 사용하는 IT 인프라를 구축·제공·운영한다. **32개 DC**, **100만 코어 이상**의 컴퓨팅 자원, 대부분의 회사 시스템이 운영되는 클라우드와 GPU 기반 AI 인프라를 맡는다.
- AI를 활용한 인프라 운영 효율화도 진행한다. 모든 인프라에 AI/IAP 적용이 완료됐다는 뜻은 아니다. 시설·인원 규모는 교육 개선 지표가 아니다. 팀 약 160명이라는 규모는 본편에서 강조하지 않는다.
- 교육의 핵심은 외부 경험을 받아들이고 자산화하며 동료의 경험을 교류해 함께 성장하는 것이다. 결속·사기·원팀 문화와 다양한 관점의 문제 해결은 팀장의 목적·관점이며 측정된 결과나 과거 직접 인용이 아니다.
- 심사위원은 학습문화와 실질 성과, 온라인 투표는 구성원이 느끼는 성과와 다른 조직으로의 확산 가능성을 평가한다. IAP와 개인 경험·공유·참여 구조를 함께 보여주며 실제 타 조직 확산 완료는 미확인이다.

## 프로그램과 실제 경험

**AI 4 AI:** Advanced Infrastructure for Artificial Intelligence. 팀 비전·영상 주제이면서 월 1회 외부 전문가 기술 세미나 이름이다. 3월 시작, 상위 센터 구성원을 대상으로 하고 녹화 후 교육 플랫폼에 공유한다. 센터 약 2천 명은 대상 조직 규모이며 참석·시청 인원이 아니다.

**Tech X:** 각 파트가 과제 하나씩 제안해 3월 팀 모집 공고를 냈다. 관심 있는 지원자 중 필요한 인원을 선발하고 4월 착수했다. 현재 **6개 과제·44명 참여 중**이다. 참가자는 일부 시간을 할애하며, 우수 과제 시상·성과 반영 제도가 있다. 근무시간 규칙·비율·수상 결과는 미제공이다. 부서의 평소 업무를 넘어 함께 일하고 경험을 교류하는 팀의 문화로 소개한다.

**이관우의 경험:** 관심이 있어 **k8s GPU 자원 효율화 과제**에 참여했다. 여러 부서의 접근 관점을 파악하고 교류하며 배우고 성장했다. GPU 효율 향상률·절감 수치·특정 논의 내용은 없다. 개인 경험을 전체 참여자의 후기나 과제 완료로 확대하지 않는다.

**IAP:** 다른 Tech X 과제에서 출발한 DC팀 특화 Infra Agent Platform이다. 팀 주요 미션으로 확장돼 개발·운영 도입을 진행한다. **서버 로그의 특정 패턴 감지 → 정해진 포맷 → 메신저 동보**가 기존 사람이 하던 일을 대체한 실제 사례다. 팀 인프라 영역 전반으로 확대는 목표다. 6월에는 팀에 소개하고, 7월에는 Agent 등록 담당자 25명을 대상으로 실습을 진행했다. 시간 절감·근본원인 분석·자동 복구·전면 적용은 미확인이다.

**Job Fair:** 8월 **11개 부서 부스**와 A0 업무 소개 패널로 서로의 일을 설명했다. 사용자 표현 ‘부서 전원’의 실제 참석 범위는 불명확하므로 ‘160명 전원 참석’으로 바꾸지 않는다.

**DCIS:** Data Center Idea Sync. 월 1회 팀 내부 세미나에서 주요 과제·업무, 서비스, 연구 기술을 공유한다. 동료의 일과 관점을 이해하는 프로그램이다. Job Fair와 함께 원팀으로 일할 기반을 설명하며 AI 전용 실습으로 분류하지 않는다.

**명장 투어:** 7월 신규 합류·복귀 구성원 등 8명을 대상으로 화성 HPC센터의 시험 중 수냉 서버·공냉 서버랙과 DC 동작을 체험한 활동이다. 센터 명장이 주관했다. 현재 본편 P08에서 현장을 통해 업무를 이해하는 사례로 소개한다. 전체 구성원이 참여한 활동으로 넓히지 않는다.
