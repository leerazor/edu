# 실제 참여 경험을 반영한 공동 해설 v02

> 이 문서에서 해야 할 일: 10월 11일 추가 확인을 대본·자료·일정에 같은 의미로 적용한다. 사용자는 PPT의 표시된 영역에 실제 자료를 붙이고, 영상팀은 10월 14일 제출본을 편집한다. 이전 세 제작본은 보존한다.

## 이번 변경의 목적

이관우 교육담당은 Tech X의 k8s GPU 자원 효율화 과제에 직접 참여했다. 이 경험을 P05/S05의 중심으로 삼는다. ‘다양한 부서의 관점을 접했고 교류하며 성장했다’는 본인 진술을 구두 대사로 다듬는다. GPU 성능·활용률 향상이나 구체적인 문제 해결 장면을 창작하지 않는다.

팀장의 결속·사기·원팀 문화에 대한 관점은 교류를 중요하게 보는 이유로 사용한다. 측정한 성과나 과거 발언의 직접 인용으로 바꾸지 않는다. IAP는 다른 Tech X 과제의 운영 적용 사례이며 S06 35초를 유지한다.

## 사실과 일정

- Tech X는 **3월 팀 모집 공고, 4월 착수**다. 각 파트에서 프로젝트 주제를 하나씩 제시하고, 희망자 중 필요한 인원을 선발했다.
- 참가자가 자신의 시간 일부를 할애한다. 구체적인 시간 비율이나 근무시간 안팎의 구분은 제공되지 않았다.
- 우수 프로젝트 시상·성과 반영은 운영 방식이다. 수상팀·시상일·실제 반영 완료는 확인되지 않았다.
- 10월 12일 OutSystems 세미나 예정, 14일 자료 제출, 16일 Tech X 최종 발표 예정, 19일 촬영이다.
- 본편은 제출일 뒤 행사를 미리 완료형으로 말하지 않는다. 12일·16일 실제 진행 확인 후 필요한 자료와 문구만 갱신한다.

## 자료를 넣는 방식

사용자가 나중에 붙일 실제 자료를 PPT 본편의 **점선 영역과 자료명·IMG ID**로 표시한다. 같은 내용을 노트·콘티·대본에도 넣는다. 이미지 생성이나 범용 사진으로 내부 행사·참여 경험을 대신하지 않는다.

점선 영역과 안내 글자는 제작용이다. 실제 자료를 넣은 뒤 지우고, 말하는 부분이 보이도록 확대한다. 원본을 사용하지 않는 장면은 영상팀이 같은 메시지의 키워드 화면으로 편집한다. 자료와 발표문을 따로 수정해 다른 사실을 말하게 만들지 않는다.

새 자료 ID는 **IMG15: 이관우 참여 k8s GPU 자원 효율화 과제의 표지·논의 자료**다. 교육 플랫폼은 기존 **IMG13**을 유지한다.
