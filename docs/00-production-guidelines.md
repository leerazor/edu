# 2026 Learning Fair 제작 지침

> 이 문서에서 해야 할 일: 제작 범위·스토리 원칙·사실 기준·납품 조건을 먼저 고정하고, 모든 후속 산출물을 이 기준으로 검수한다.

## 1. 만들어야 할 결과

- 교류와 성장을 중심으로 한 콘셉트 및 스토리라인.
- 최종 편집 5분을 기준으로 한 타임라인과 장면별 콘티.
- 팀장님과 교육담당 2인의 실제 촬영용 대본. 각 장면에 발화자, 자료 등장 시점, 효과, 촬영 지시를 기재한다.
- 영상팀이 리디자인할 수 있는 간단한 16:9 PPTX. 본편 장표와 참고 부록을 구분한다.
- 출처를 갖춘 웹 참고자료 목록, 활용 지점, 내부 증빙·이미지 수집 목록.
- 발화량·러닝타임·자료 번호의 일치 검수와 영상팀 전달 문서.
- 모든 제작 산출물과 Markdown 문서를 `https://github.com/leerazor/edu`의 `main`에 커밋하고 푸시한다. 기존 원격 이력이 있으면 보존한다.

## 2. 러닝타임

최종 편집 목표는 300초다. 회사 제공 인트로 5초, 별도 AI 팀 소개 15초, 회사 제공 아웃트로 5초를 빼면 팀 발표·리뷰는 **275초(4분 35초)**다. 자료 전환과 호흡도 이 275초 안에 포함한다.

10분은 촬영 발화량의 상한이며 목표 길이가 아니다. 최초 대본은 5분 편집을 우선한다. 발화량은 한국어 읽기 단위로 추정하고, 영문·숫자의 실제 발음과 쉬는 시간을 반영한다. 추정치는 리허설 실측으로 교체한다.

## 3. 핵심 스토리 원칙

- 타이틀에 `AI 4 AI`를 사용한다. 공식 확장명은 `Advanced Infrastructure for Artificial Intelligence`다.
- AI를 위한 인프라를 제공하고 AI를 활용해 인프라 운영을 발전시키는 두 방향을 연결한다.
- 교육 프로그램명 순서로 설명하지 않는다. 사람과 지식의 이동, 부서 간 이해, 공동 실행, 재공유를 중심으로 구성한다.
- **2026-10-10 사용자 보완:** 영상의 주인공은 구성원의 교류와 학습문화다. IAP는 대표 성과 사례 중 하나이며, 도입부터 결말까지 IAP를 따라가는 서사나 다른 활동을 IAP의 배경으로만 다루는 구성은 사용하지 않는다. 분량과 화면 효과 모두 이 위계를 따른다.
- Tech X와 IAP를 실행 사례로 다루되, 특정 세미나가 IAP를 직접 만들었다는 인과는 증거 없이 쓰지 않는다.
- 성과 수치와 참여 규모를 구분한다. 업무 시간 감소율, 만족도, 이용률 등 제공되지 않은 수치를 만들어 넣지 않는다.
- 정적인 스튜디오 촬영에서도 구현 가능한 콘셉트를 선택한다. 팀장님은 방향과 의미, 교육담당은 사례와 연결을 설명한다.

## 4. 자료와 사실

팀 활동 사실은 사용자 제공 브리프가 출발점이다. 웹 자료는 기술 배경, 영상 표현 참고, 외부 이미지 후보에 사용한다. 웹상의 일반 사진을 우리 팀 행사·시설의 실제 모습으로 제시하지 않는다.

외부 자료는 URL, 확인일, 활용 위치, 이미지 이용 조건을 남긴다. 다운로드 가능한 이미지라도 이용 조건을 확인한다. 실제 내부 사진·IAP 화면이 없으면 자리표시자를 사용하고, 허구의 현장 사진을 만들지 않는다. 전문 영상팀이 적용할 회사 KV·폰트는 미수급 상태로 표시한다.

10월 세미나의 실제 개최 여부, 공식 프로그램 표기, 참석 범위, 공개 가능한 실적은 확인 항목으로 관리한다. 이름 미제공 출연자는 역할명으로 표기한다.

## 5. 장표와 촬영

- 장표는 한 장에 메시지 하나. 큰 키워드, 짧은 보조 문장, 원본 이미지 영역으로 구성한다.
- 모든 도식·표는 편집 가능하게 만들고, 실제 수치가 없는 그래프는 만들지 않는다.
- 본편 자료 번호는 `P01`부터 부여하고 대본·콘티·PPTX에 동일하게 사용한다.
- 사진 자리표시자에는 필요한 원본과 의미를 명시한다.
- 애니메이션은 영상팀이 구현할 최소 지시로 문서화한다. PPTX에 적용하지 않은 효과를 적용했다고 기록하지 않는다.
- 장표 등장 지점은 대본 내 `[P01 등장]`처럼 발화와 연결하고, 최종 타임코드와 별도로 표시한다.

## 6. 작업 순서와 완료 조건

1. 이 지침과 후속 작업 지침을 먼저 저장한다.
2. 콘셉트 후보를 비교하고 추천안을 중심으로 전체 스토리를 확정한다.
3. 사용자 브리프의 사실 표와 공개 웹 출처를 정리한다.
4. 300초 타임라인 → 장면 대본 → PPTX 순으로 작성한다.
5. 발화량, 자료 참조, 페이지 수, 합계 시간, 열람 가능 여부를 검수한다.
6. 산출물·재생성 명령·남은 확인 항목을 문서화하고 `main`에 푸시한 SHA를 확인한다.

완료는 **콘셉트가 연결된 검토용 제작 패키지를 납품한 상태**다. 사내 원본 자료 확보, 전문 촬영·편집, 회사 KV 적용, 내부 사실 검토 완료는 후속 제작 단계다.
