## 사진 삽입용 제작본 사용 방법

이 PPTX는 사용자가 실제 사진·화면 원본을 나중에 붙이는 제작본이다. 점선 영역의 ‘자료 삽입’ 안내와 IMG ID는 교체할 편집 가능한 도형이다. 빈 삽입 영역을 최종 영상으로 그대로 사용하라는 뜻이 아니다. 최종 편집 전 해당 실제 자료를 삽입하고 안내 글자와 점선을 제거한다. 원본을 쓰지 않으면 영상팀이 같은 메시지의 키워드 화면으로 다시 구성한다.
