## 흐름과 남는 한계

팀 역할·AI 4 AI 비전·교류 문화를 먼저 설명하고, 같은 기준으로 세 번 선택한다. 첫 경기의 외부 지식·Tech X 비교에 개인 경험을 더한 뒤, 함께 일할 동료의 업무를 이해하는 Job Fair·DCIS로 이어진다. 결승에서는 꾸준한 공유와 공동 경험을 비교하고 작은 과제·타부서 참여라는 시작 방법을 남긴다. 결말은 전체 문화와 커지는 AI 인프라 미션으로 돌아온다.

상호 보완적인 활동을 승자·탈락자로 나누므로 관계 설명과 출연자의 호흡에 더 의존하는 한계가 있다. ‘사실 모두 우승’ 반전을 넣지 않는다. 현재 추천은 흐름형이며 이 안은 비교 대안이다. 실제 출연자의 선택·사진·낭독·회사 KV는 아직 확인 전이다. [검증 보고서](../../deliverables/worldcup-v02/validation-report.json)의 발화 시간은 추정이다.

이관우의 **사진 1·2는 아직 원본 파일을 받지 않았다.** IMG16·IMG17 영역은 사용자가 제공할 사진 자리다. 삽입 후 안내 글자·ID·테두리를 제거한다. 자료가 없는 장면은 같은 내용을 설명하는 키워드·도식과 인물 화면으로 편집한다. 가상 현장 사진이나 미확인 성과를 만들지 않는다.

실제 자료는 기본 PPTX를 복사해서 넣는다. 예를 들어 `learning-fair-2026-worldcup-v02-1014-submission.pptx`는 제출 사본 이름 예시다. 자동 빌드는 기본 출력 파일을 다시 쓰므로 수동 삽입본은 별도 보관한다. 현재 PDF·PNG는 원본 삽입 전 제작본이다. 삽입 뒤 PDF도 다시 내보낸다.

## 촬영과 효과

팀장은 팀 역할·커지는 미션·교육의 의미를 말하고, 교육담당은 운영 방식과 본인의 경험을 보탠다. 팀장도 세미나 공유와 교류의 구체적인 내용을 짚는다. 서로 처음 듣는 듯한 반응이나 과거에 직접 지시했다는 회고를 추가하지 않는다. 이름·직함은 첫 개인 화면에 표시한다.

숫자와 제목은 완성형으로 띄운다. 본편 하단의 공통 진행표로 지금 다루는 학습 행동을 알려준다. 의미가 바뀔 때 현재 단계를 한 번 강조하고, 매 장표에 새 음악·코너 오프닝을 붙이지 않는다. IAP는 18초 안에 로그→지정 형식→메신저 알림만 강조한다. 사진과 선택 화면은 대사 위에 겹쳐 쓰고 별도 시간을 더하지 않는다. PPT에는 실제 애니메이션을 넣지 않았다.

## 월드컵 공개 화면

**모든 경기의 기준:** 다른 조직에도 권하고 싶은 교류 방식은?

출연자의 과거 취향·실제 조사·투표·교육 효과 순위가 아닌 촬영용 추천 대사다. 모든 경기는 같은 기준으로 선택한다. IAP는 후보가 아니라 Tech X의 짧은 대표 사례다. 실제 출연자의 선택이 바뀌면 대진·대사·선택 화면을 함께 수정한다.

- [선택 전·후 PPTX 6장](../../deliverables/worldcup-v02/choice-states.pptx) · [PDF](../../deliverables/worldcup-v02/choice-states.pdf)

| 경기 | 선택 전 / 후 페이지 | 공개 발화 | 제안 선택 |

| M01 준결승 1 | 1쪽 / 2쪽 | S04 ‘첫 번째는 Tech X로 가겠습니다.’ | Tech X |

본문의 비교 장표에는 승자를 미리 표시하지 않았다. 비교·대화 중에는 선택 전 화면, 공개 발화부터 선택 후 화면을 사용한다. 이 6장은 본편에 추가할 시간이 아니다. 다른 선택으로 촬영한다면 원본 JSON의 승자·결승 대진·대사·큐·공개 화면을 함께 수정하고 재생성한다.
