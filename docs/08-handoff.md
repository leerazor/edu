# 영상팀 전달과 촬영 준비

> 이 문서에서 해야 할 일: 전달 파일을 역할별로 읽고, 실제 행사·IAP 원본을 장면에 매칭하며, 회사 디자인과 리허설 결과를 반영해 촬영·편집용 버전을 확정한다.

**상태:** 2026-10-09 검토용 초안 v0.1. 출연자는 **류경동 팀장·이관우 교육담당**. 아직 촬영·영상 편집을 진행한 상태는 아니다. 이 문서는 전달 패키지를 설명하며 영상팀에 별도로 발송하지 않았다.

## 2. 이번 영상의 이야기

**밖에서 배우다 → 서로를 이해하다 → 함께 바꾸다 → 다시 나누다.**

AI를 위한 인프라를 제공하는 팀이 AI를 활용해 운영도 발전시킨다는 역할과, 사람·지식·경험이 오가는 교육문화를 연결한다. 이 흐름은 연간 활동의 시간순이나 프로그램 사이의 직접 인과를 표현한 것이 아니다. 3월 선발한 Tech X를 8월 Job Fair의 결과로 편집하지 않는다.

심사위원에게는 IAP의 **팀 주요 미션 승격·운영 도입·수작업 대체·실무 전달**을 중심으로 보여준다. 구성원에게는 Tech X의 **새로운 일에 참여하는 경험·부서 간 교류**와 다른 조직도 시작할 수 있는 **교류 열기 → 작은 공동 과제 → 다시 공유**를 남긴다. 실제 다른 조직 도입이 완료됐다는 주장은 하지 않는다.

## 3. 길이와 촬영 방식

- 00:00~00:05 회사 인트로, 00:05~00:20 AI 소개, 00:20~04:55 스튜디오 본편, 04:55~05:00 회사 아웃트로.
- 본편은 **275초(4분 35초)**. IAP 기능과 실행 사례 P06에 **43초**를 배정했다.
- 현재 발화량은 발음 환산 **1,012음절**. 기본 호흡을 포함해 본편 기준 속도 약 242초, 느린 속도 약 263초로 추정한다. 275초까지의 차이는 자료·표정·전환 홀드로 사용한다.
- 최소 호흡 예산에 실제 발화자 특유의 쉼이 충분히 반영되지 않을 수 있다. 장면별 리허설로 확인한다. 합계만 맞추고 한 장면의 시간 초과를 지나치지 않는다.
- 팀장님은 방향과 핵심 성과, 교육담당은 교류 사례와 활용 확산을 말한다. 인사와 마지막 공동 발화 블록만 두 사람이 함께 읽는다.
- 기본 컷은 2인 풀샷과 개별 정면 클로스업이다. 측면샷은 영상팀의 촬영 여건에 따라 사용하며, 정면 촬영만으로도 편집 가능하다.
- 장표는 매 순간 전체 화면에 두지 않아도 된다. 발화 큐에서 전체 자료 또는 인물·자료 분할 화면으로 전환한다.

## 4. PPTX 리디자인 지시

PPTX는 **본편 10장 + 참고 부록 3장**이다. A01~A03은 슬라이드 쇼에서 숨김 상태다. 검토용 PDF에는 참고를 위해 모두 포함했다. 자료 번호는 리디자인 뒤에도 유지하거나 새 번호 대응표를 만든다.

| 형태 | 해당 자료 | 리디자인·활용 지시 |
| --- | --- | --- |
| 키워드·숫자 | P01, P03, P05, P10 | 영상팀의 회사 KV 컬러·폰트 톤에 맞춘다. 수치를 비율·개선 성과로 바꾸지 않는다. |
| 편집 가능한 도식 | P02, P06, P09 | 현재 도식을 전달 원본으로 사용 가능하다. 글자·배경의 대비와 화살표 의미를 유지한다. P06은 실제 동작 사례, P09는 문화 모델·확산 제안이다. |
| 이미지 소개 | P03, P04, P07, P08 | 지정된 내부 원본을 넣고 영상팀이 구도·크기·전환을 조정한다. 자리표시자·IMG 번호는 최종 영상에서 제거한다. |
| 참고 부록 | A01~A03 | 본편에 사용하지 않는다. 월별 사실, 수집 체크, 범용 이미지 참고용이다. |

현재 색상은 차콜·민트·라일락, 폰트는 맑은 고딕이다. 공식 회사 KV를 적용했다고 주장하지 않는다. 각 장표의 작은 ‘검토용 초안’ 표시는 최종 영상에서 제거한다. 실제 PPTX에는 애니메이션이 없으며 연결선 점등·순차 팝업은 콘티와 대본에 적힌 **후반 편집 지시**다.

## 5. 핵심 성과 화면 P06

현재 확인된 사용 사례는 **서버 로그에서 특정 패턴을 감지하면 정해진 포맷으로 메신저 동보를 자동 처리하여 사람이 하던 일을 대체**하는 것이다.

1. ‘팀 주요 미션’ 발화에서 과제→미션→운영 도입 문구를 보여준다.
2. ‘서버 로그에서 특정 패턴을 감지하면’ 발화에서 **로그 패턴 감지 → 정형 메시지 → 메신저 동보**를 순서대로 강조한다.
3. IMG08 실제 화면이 있으면 5초 정도 삽입한다. 이 5초는 해당 발화와 겹쳐 사용하며 별도로 더하지 않는다.
4. 화면이 없으면 현재 편집 가능한 기능 도식을 사용한다. 임의로 만든 로그·메신저 화면을 실제 사용 증거로 보여주지 않는다.
5. ‘인프라 전반’은 적용 범위를 확대하려는 목표로 표현한다. 전 영역 적용 완료, 정량 시간 절감, 자동 원인 분석·장애 복구는 아직 주장하지 않는다.

## 6. 원본 확보 우선순위

**최우선:** IMG08의 IAP 대표 기능·메신저 알림 화면, IMG10의 실무 실습, IMG07의 Tech X 과제·참여 현황 근거. 심사와 온라인 투표의 주요 근거다.

**다음:** IMG02~06 교류 장면, IMG11~12 실제 HPC센터 투어, IMG13 교육 플랫폼 녹화 목록. 자료가 없으면 실제 사실을 담은 키워드·도식과 스튜디오 화면으로 이어간다.

**공통:** IMG14 회사 인트로·아웃트로와 KV·폰트. 실제 파일의 정확한 길이가 5초씩인지 확인한다. 원본 사진과 화면의 공식 명칭·공개 가능한 범위는 소관 부서 기준으로 확인한다.

외부 서버 사진 3장은 실제 팀·화성 HPC센터 사진이 아니다. A03에 사용한 두 장은 CC0 범용 참고 사진이며, 출처를 발표자 노트와 웹 참고 문서에 기록했다. CC BY-SA 액체 냉각 사진은 자료 폴더에만 보관했다.

## 7. 촬영 직전 확인과 수정

- 출연 이름: 류경동 팀장·이관우 교육담당 확인 완료. 자막의 공식 조직 표기 검토.
- 10월 OutSystems: **현재 미개최·촬영 전 개최 예정**. 개최 후 A01·사실 문서에 실제 개최일과 상태를 반영. 본편은 완료 횟수를 말하지 않으므로 미개최여도 그대로 촬영 가능.
- 수치: 6개/44명, 11개 부서, 실습 25명, 투어 8명, 팀 약 160명·센터 대상 약 2천 명의 의미와 촬영 시점 상태 확인.
- 발화 큐·자료 페이지·이미지 교체 결과를 대본과 맞춰 확인.
- 실측 후 긴 경우 IAP 핵심 설명을 먼저 보존하고 보조 사례의 문장을 압축. 더 큰 수정이 필요하면 명장 투어 P08을 짧은 화면 컷으로 바꾸고 타임라인을 다시 계산.
- 정량 성과는 사용자가 추후 정리할 예정이다. 그때 산출 근거·측정 기간·범위를 함께 받아 수정하며, 현재 초안에서는 요구하지 않는다.

## 8. 다음 수정의 기록 방식

발화·시간·자료 큐의 기준은 `content/film.json`이다. 수정 후 `scripts/build_package.py`로 대본·콘티·PPTX를 재생성한다. CSV의 실측·메모 칸은 유지되지만 발화가 바뀐 장면은 다시 읽는다. PDF·미리보기는 PowerPoint에서 다시 렌더하고 검수한다. 변경된 사실은 `docs/03-facts-and-assets.md`와 콘셉트 문서에도 반영한다.

최종 영상은 전문 영상팀이 촬영·편집한다. 이 패키지에는 실제 촬영본과 AI 소개 영상 파일이 포함되어 있지 않다.
