# 월드컵 추가 버전 제작 지침

> 이 문서에서 해야 할 일: 선택형 진행의 질문·대진·사실 기준을 먼저 고정하고, 월드컵 버전의 콘티·대본·장표·편집 지시를 같은 기준으로 작성한다. 기존 본편을 유지하면서 별도 산출물을 생성하고 실제 검수 결과를 남긴다.

**상태:** 2026-10-10 제작 지침 초안. 이 문서는 생성·검수 기준이며, 산출물 생성이나 검증 완료를 뜻하지 않는다. 공통 사실은 `docs/03-facts-and-assets.md`를 따른다.

## 1. 이번 버전의 목적

교육담당 이관우와 팀장 류경동이 **“다른 조직에 권하고 싶은 교류 방식은?”**이라는 한 질문 아래 두 후보씩 비교하고 선택 이유를 설명한다. 후보를 고르는 진행이 서로 배우고 함께 일하는 문화의 효용을 드러내도록 한다. 행사명·실적을 빠르게 나열하는 형식으로 만들지 않는다.

기존 `content/film.json`, `docs/05-storyboard.md`, `docs/06-script.md`, `deliverables/learning-fair-2026.*`는 유지한다. 이 버전은 `content/worldcup-film.json`과 `docs/worldcup/`, `deliverables/worldcup/`에 독립적으로 저장한다. 기존본을 이 버전으로 덮어쓰지 않는다.

## 2. 질문과 대진

| 단계 | 후보 | 촬영용 선택안 | 설명에서 드러낼 차이 |
| --- | --- | --- | --- |
| 4강 1 | AI 4 AI 세미나 vs Job Fair | Job Fair 진출 | 외부 전문가의 시선과, 서로의 업무를 직접 이해하는 교류 |
| 4강 2 | 명장 투어 vs Tech X | Tech X 진출 | 현장에서 전수받는 경험과, 다른 부서의 과제에 함께 참여하는 경험 |
| 결승 | Job Fair vs Tech X | Tech X 선택 | 서로를 알아가는 접점과, 함께 해보고 배운 것을 나눌 수 있는 방식 |

**위 선택은 촬영용 구성안이다. 실제 투표 결과·출연자의 확정된 선호·팀의 공식 프로그램 평가가 아니다.** 현재 선택을 전제로 초안을 쓰되, 리허설에서 실제 의견이 바뀌면 발화·결승 후보·진출선·최종 화면을 함께 수정한다. 한 후보의 선택은 다른 후보의 가치가 낮다는 평가로 표현하지 않는다.

팀장도 교류 방식의 효용과 현업에서 어떻게 활용할 수 있는지 궁금해하며 선택 이유를 말한다. 교육담당만 정보를 제공하고 팀장은 승자 이름만 읽는 구성을 피한다. 후보별 효과를 같은 단위의 점수·성과율로 환산하지 않는다.

## 3. 내용과 사실 범위

- **AI 4 AI 세미나:** 3월부터 월 1회 외부 전문가 초빙, 센터원 대상, 녹화·플랫폼 공유. 약 2천 명은 대상 조직 규모이며 누적 참석·시청 수가 아니다. 10월 OutSystems는 현재 미개최·촬영 전 개최 예정으로 표시하고 촬영 전에 확인한다.
- **Job Fair:** 8월, 11개 부서 부스와 A0 업무 소개. 팀 약 160명 전원의 실제 참석으로 바꾸지 않는다. DCIS의 정기 공유는 필요할 때 설명의 보조 사례로 쓰며 4강 후보를 추가하지 않는다.
- **명장 투어:** 7월 1회, 8명, 화성 HPC센터에서 명장과 함께 시험 중 수냉식 서버·공냉식 서버랙을 체험. 외부 시설 사진을 우리 센터의 실제 현장으로 쓰지 않는다.
- **Tech X:** 3월 선발, 6개 프로젝트·44명 참여 중. 완료 프로젝트 수·누적 수료 인원으로 바꾸지 않는다. 부서 밖의 관심 과제에서 함께 경험을 쌓는 방식이 핵심이다.
- **IAP:** 독립 후보가 아니라 Tech X의 대표 사례다. **한 장·40초** 안에서 실제 기능과 재공유를 설명한다. 로그의 특정 패턴 감지 → 정해진 포맷의 메신저 동보로 사람이 하던 일을 대체한 사실, 6월 팀 소개, 7월 실무 담당자 25명 실습을 포함한다.
- IAP의 인프라 전반 적용 확대와 다른 조직의 프로그램 적용은 목표·가능성이다. 전 영역 적용 완료·타 조직 확산 완료를 주장하지 않는다. 시간 절감·만족도·오류율·시청 수 등 미제공 숫자와 실제처럼 꾸민 후기는 넣지 않는다.
- 외부 세미나·Job Fair·명장 투어가 Tech X나 IAP를 직접 만들었다는 인과를 대진표나 연결선으로 표현하지 않는다.

## 4. 길이와 촬영

최종 목표는 **300초**다. 회사 인트로 5초 → 별도 AI 팀 소개 15초 → 스튜디오 본편 275초 → 회사 아웃트로 5초. 후보 소개·선택 대화·짧은 효과음·브래킷 전환·인사·자료 홀드는 모두 본편 275초 안에 포함한다. 별도 AI 소개의 공통 조건은 `docs/07-ai-intro-brief.md`를 참고한다.

회사 스튜디오에서 류경동 팀장·이관우 교육담당 2인이 촬영한다. 기본 화면은 2인샷·개별 정면·자료 전체 화면이다. 효과에 맞춰 연기하거나 화면을 가리키는 동작을 필수로 만들지 않는다. 자료는 실제 발화 큐에 맞춰 후반 편집한다.

발화량은 추정과 리허설 실측을 구분한다. 10분 촬영 발화 상한을 채우지 않으며 최종 5분에 맞춰 쓴다. 선택 이유를 설명하는 호흡·발화자 교대도 장면 예산에 포함한다.

## 5. 장표와 모션

- 16:9, 큰 후보명·짧은 차이·실제 사진 영역 중심. 대진표·후보 카드·도식은 편집 가능한 원본으로 만든다. 장표 번호는 원본 JSON·콘티·대본·발표자 노트에 일치시킨다.
- **PPTX에 네이티브 애니메이션을 넣는 범위가 아니다.** 후보 공개·진출선 강조·선택 효과는 문서와 노트의 편집 큐로 전달하고 전문 영상팀이 구현한다. 정지 장표만 봐도 대진과 의미가 읽혀야 한다.
- 주효과는 선택한 후보·진출선의 짧은 강조와 필요한 자료 컷 전환이다. 짧은 선택 효과음은 사용할 경우 발화와 겹치지 않게 장면 안에 배치한다. 카운트다운·반복 점멸·긴 환호로 분량을 늘리지 않는다.
- 선택하지 않은 후보는 읽을 수 있게 유지한다. 흑백 처리·낙인·폭발·조롱·성과 점수판을 사용하지 않는다. ‘선택’과 ‘진출’은 화면의 진행 상태를 뜻한다.
- 키워드·후보 카드는 회사 KV·폰트로 리디자인할 수 있다. 그대로 활용할 가능성이 높은 대진표·IAP 도식은 원본에서 글자 크기·대비·화살표 의미를 먼저 정리한다. 회사 KV는 미수급이다.
- 내부 사진·실제 IAP 화면은 미제공이다. IMG 코드와 요청 원본을 표시하고 최종 편집에서 교체한다. 실제 원본이 없으면 사실에 맞는 키워드·도식을 사용한다. 허구의 로그·메신저 화면을 실제 증빙으로 생성하지 않는다.

## 6. 만들어야 할 파일

| 역할 | 경로·해야 할 일 |
| --- | --- |
| 발화·시간·선택·큐의 원본 | `content/worldcup-film.json`에 작성. 이후 수정의 기준으로 사용 |
| 패키지 생성 | `scripts/build_worldcup_package.py`로 월드컵 전용 산출물 생성 |
| 렌더 | `scripts/render_worldcup_slides.sh`로 월드컵 PPTX의 PDF·미리보기 생성 |
| 검수 | `scripts/validate_worldcup_package.py`로 자료·대진·러닝타임·파일 구조 검수 |
| 콘티·대본 | `docs/worldcup/01-storyboard.md`, `docs/worldcup/02-script.md` 생성 |
| 촬영·검토 자료 | `deliverables/worldcup/learning-fair-2026-worldcup.pptx`, `.pdf`, `preview/`, `teleprompter.txt` 생성 |
| 실측·검수 기록 | `deliverables/worldcup/rehearsal.csv`, `timing-report.json`, `validation-report.json` 생성 |
| 제작 전달 | `docs/worldcup/03-handoff.md`에 파일 역할·편집 지시·남은 확인 정리 |

위 경로는 제작 대상이며 이 지침 작성 시점의 존재·완료 상태를 보증하지 않는다. 생성 후 실제 파일과 결과를 확인해 상태를 기록한다. 모든 산출물과 문서는 기존본과 함께 저장소 `main`에 반영한다.

## 7. 완료 조건

300초 합계, 후보 4개·대진 3개, 예정 선택과 브래킷의 일치, IAP 한 장·40초, 자료 번호·큐 대응, PPTX 편집 가능 여부와 PDF·미리보기 열람을 실제로 검수한다. 결과는 검수 보고서에 남긴다. 내부 원본·회사 KV·리허설·전문 촬영·최종 편집은 후속 제작 단계로 구분한다.
