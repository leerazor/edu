## 제작과 확인

2026-10-11까지 사용자 제공 사실과 이번 추가 지시를 반영한 별도 제작본. 7만 명 이상·32개 DC·100만 코어 이상은 사용자 확인 규모이며 내부 증빙을 독립 검증한 수치는 아니다. 실제 GPU 과제 경험은 본인 진술을 촬영용으로 다듬었다. 발표자의 의견과 선택은 촬영용 제안이며 과거 발언·실제 투표를 뜻하지 않는다. 세미나·프로젝트·업무 교류의 연결은 교육문화의 설명 순서이며 직접 인과나 연대기가 아니다. IAP는 짧은 Tech X 대표 사례다. 미제공 GPU 성과·시간 절감·수상 결과는 주장하지 않는다.

현재 내부 행사 사진·화면 원본은 미수급이다. 원본이 없으면 JSON에 정의된 키워드·도식과 스튜디오 화면으로 제작한다. 범용 외부 사진을 실제 사내 시설·행사 증거로 사용하지 않는다. 원본 수집과 사실 확인은 docs/03-facts-and-assets.md를 따른다.

PPTX에는 실제 애니메이션이 없다. 자료 전환과 모션은 영상팀 편집 지시이며 각 장면 시간 안에서 구현한다. 숨김 부록 A01~A03은 본편 사용 제외지만 검토 PDF·PNG에는 포함된다.

프로그램 사이의 연결은 교육문화의 관점을 설명한다. Job Fair가 Tech X를 발생시켰거나 세미나가 IAP 개발의 직접 원인이었다는 인과를 표현하지 않는다. 10월 세미나 상태는 개최 확인 후 갱신한다.

content/worldcup-v02-film.json을 수정한 뒤 이 버전 빌더로 다시 생성한다. 이전 기본본·월드컵본·공동 해설 v01–v05는 별도 원본·산출물로 보존한다.

## 월드컵 선택과 공개 화면

**세 경기의 공통 기준:** 다른 조직에도 권하고 싶은 교류 방식은?

출연자의 과거 취향·실제 조사·투표·교육 효과 순위가 아닌 촬영용 추천 대사다. 모든 경기는 같은 기준으로 선택한다. IAP는 후보가 아니라 Tech X의 짧은 대표 사례다. 실제 출연자의 선택이 바뀌면 대진·대사·선택 화면을 함께 수정한다.

choice-states.pptx는 M01·M02·M03의 선택 전·후 화면 6장이다. 본편에 추가할 장면이나 시간이 아니다. 대본의 선택 공개 큐에서 해당 상태로 교체한다.
