# 실제 대사와 화면을 만든 뒤의 비판적 검토

> 이 문서에서 해야 할 일: 채택한 방향뿐 아니라 탈락 이유와 남은 약점을 읽는다. 출연자 의견과 실제 자료를 받으면 해당 대사·화면만 원본 JSON에서 고치고, 새 버전을 다시 생성한다. 기존 기본본·월드컵본은 보존한다.

검토일: 2026-10-11. [이전 방향 판단](../17-format-decision.md)을 그대로 제작하지 않고, 독립 편집 검토와 실제 대사·PowerPoint 화면 확인을 거쳐 수정했다. 아래 평가는 제작자의 편집 판단이며 시청자 조사나 출연자 리허설 결과가 아니다.

## 1. 대사로 시험한 세 안

| 안 | 도입과 연결 예시 | 비판적 판단 |
| --- | --- | --- |
| 기존 공동 해설: Tech X 먼저 | “다른 부서에서 하는 일, 직접 배워볼 수 있다면 어떨까요?” → Tech X → IAP → 프로젝트 밖의 동료 → Job Fair | 강한 적용 사례 뒤에 기본 업무 소개로 돌아가 설명의 힘이 떨어진다. Job Fair가 프로젝트 비참여자의 보완책이라는 인상도 실제 목적과 다르다. 순서를 유지할 이유가 부족하다. |
| **동료의 일을 알아보고 직접 해보기** | “같은 팀이어도, 다른 부서가 무슨 일을 하는지 자세히 알기는 어렵습니다.” → 업무 소개·정기 공유 → 참여 기회 → 실제 적용 한 사례 → 외부 전문가와 녹화 공유 | 현재 자료로 가장 자연스럽게 말할 수 있다. 실제 행위가 먼저 나오고 의미는 짧게 보탠다. **제작안으로 채택.** |
| 올해 남긴 자료 세 장 | “올해 교육을 설명할 자료를 세 장 골랐습니다.” → 업무 소개 판넬 → 과제 목록 → 녹화 화면 | 원본이 없는 지금은 숫자 장표를 세 장 보여주는 새 목록에 불과해진다. ‘세 장’이라는 규칙도 내용의 필요에서 나온 것이 아니다. 전체 형식에서는 제외한다. |

제목은 **「AI 4 AI — 그 일, 같이 해볼까요?」**로 정했다. 실제 직원 발언을 인용한 문장이 아니라 영상이 건네는 제안이다. 앞선 제목보다 직접 말할 수 있는 문장이고, 다른 조직이 작은 과제를 함께 해보자는 결말과 맞는다. 방송 세트·진행 규칙·사회자 캐릭터는 추가하지 않는다.

## 2. 기존 추천에 대한 반론과 실제 변경

### “질문이 다음 행사 이름을 부를 뿐 아닌가?”

맞는 지적이다. ‘프로젝트 밖 동료에게 열린 학습 접점’ 같은 문장을 구두 대사에 쓰지 않았다. 전체 도입은 실제 고민으로 낮추고, 중간 전환은 짧은 설명으로 바꿨다.

- 기존: “내 부서 밖의 지식과 경험을 어떻게 함께 배울 수 있을까요?”
- 변경: “같은 팀이어도, 다른 부서가 무슨 일을 하는지 자세히 알기는 어렵습니다.”
- Tech X 전환: “다른 부서의 일을 듣는 자리와 함께, 그 일에 직접 참여할 기회도 열었습니다.”

이 순서는 설명의 순서다. 8월 Job Fair가 3월 Tech X의 출발점이었다고 말하지 않는다. 화면에서도 두 행사를 연혁 화살표로 연결하지 않는다.

### “Tech X 75초를 채울 만큼 경험담이 있는가?”

현재 없다. 취지·참여 방식·6개 과제·44명 외에 다른 프로젝트의 상세 내용이나 개인의 변화는 제공되지 않았다. 설명 37초와 참여 규모·다음 사례 연결 15초, 합계 **52초**로 줄였다. 이 안의 대표 결과인 IAP는 별도 **35초**다. 부족한 분량을 새로운 성과·후기로 채우지 않았다.

### “팀장은 의미만 말하고 담당자는 숫자만 읽지 않는가?”

초안에는 그런 경향이 있었다. 팀장은 DCIS 운영과 IAP 기능도 설명한다. IAP에서는 ‘사용할 담당자가 직접 익히는 시간도 필요하겠죠’라고 활용 교육을 짚고, 교육담당이 실제 소개·실습을 설명하도록 고쳤다. 팀장이 현장에 참석했다거나 프로그램을 직접 지시했다는 회고는 넣지 않았다. 교육담당도 다음 조직이 어떻게 시작할지 의견을 보탠다.

### “AI 4 AI가 마지막에 붙인 세미나 아닌가?”

이 위험은 남는다. 처음에 AI 인프라를 제공하는 팀의 역할과 우리도 기술을 배워야 한다는 필요를 말하고, P01에 공식 영문 의미를 표시했다. 뒤에서는 실제 운영에 AI를 쓰는 주제와 AI 인프라를 다루는 주제를 나란히 보여준다. 세미나·녹화 공유에는 **67초**를 배정했다. 세미나가 IAP 개발을 낳았다는 인과는 만들지 않는다.

### “DCIS를 넣으면 다시 프로그램 수가 늘지 않는가?”

독립 검토자는 별도 장면의 설명이 약하다고 지적했다. 두 사람이 같은 의미를 되풀이하던 대사를 팀장의 한 설명으로 줄였다. 월 1회 진행 중인 과제·서비스·기술을 소개한다는 사실은 정기적인 내부 학습을 보여주는 근거라 **20초를 유지**했다. 긴 이름 해설과 별도 코너 오프닝은 없다. 명장 투어는 이번 본편에서 제외했다.

## 3. 실제 초안에서 덜어낸 문장

| 초안의 문제 | 수정 결과 |
| --- | --- |
| 녹화·다시 보기·공유를 두 사람이 35초 동안 반복 | 팀장의 한 설명으로 축약하고 20초로 줄임 |
| Tech X에서 ‘다른 일을 해본다’를 두 화자가 반복 | 팀장은 동료가 일하는 방법을 배울 기회라는 관점을 보탬 |
| ‘새로운 컴퓨팅 환경을 배웠다’라는 모호한 결과 | 국가슈퍼컴퓨터와 기술 흐름을 다뤘다는 실제 주제로 수정 |
| ‘다음 동료에게 기회가 생기면 좋겠다’라는 희망으로 결말 확장 | 함께 해볼 과제와 경험을 나눌 대상을 정하자는 행동으로 마무리 |
| 교육 플랫폼 원본 ID가 투어 사진을 가리킴 | P08·부록·추가 큐를 IMG13으로 통일. P07은 IMG02·03 |
| 장면별 느린 발화 추정 초과 | 반복 문장을 줄이고 배정 시간을 다시 맞춤. 리허설 실측은 별도 |

‘맞습니다’, ‘놀랍네요’, ‘그때 기억나시죠’ 같은 반응을 붙여 자연스러운 척하지 않았다. 역할에 맞는 구체적인 내용으로 관심을 드러내도록 했다.

## 4. 실제 PowerPoint 렌더를 보고 수정한 화면

기존 네이비·민트 카드 화면과 구별되도록 밝은 바탕, 짙은 글자, 한 가지 청록 강조색을 썼다. 이는 회사 공식 KV가 아니라 검토용 편집 방향이다. 키워드 장표는 영상팀이 회사 KV로 리디자인할 수 있다.

파일 구조 검증에 통과한 첫 렌더에도 시각적 문제는 남아 있었다. 실제 PNG 컨택트시트와 개별 장표를 열어 다음을 고쳤다.

| 발견한 문제 | 화면 변경 |
| --- | --- |
| P02의 11개가 작은 보조 정보에 묻힘 | 설명과 숫자를 좌우로 나누고 숫자를 크게 배치 |
| P05의 6개·44명이 일반 제목처럼 보임 | 두 숫자를 각각 크게 표시. 카운트업 효과는 사용하지 않음 |
| P03·P09의 빈 공간에 비해 핵심 문장이 작음 | 핵심 문장을 아래로 내려 크게 배치하고 보조 문장과 거리를 둠 |
| P04·06·07·08이 모두 아래쪽 열 배치로 반복 | P08은 실제 ‘세미나 → 녹화 → 교육 플랫폼’ 순서로 배치 |
| P06 제목 ‘로그를 확인하고 알리던 일을’이 미완성 | ‘로그 알림 업무를 자동화했습니다’로 완결 |
| P06 하단의 ‘담당자’가 한 글자만 다음 줄로 넘어감 | ‘에이전트 등록 실무자’로 줄임 |
| 본편 하단에 ‘참여 방식을 설명한 도식’ 같은 제작 설명 | 본편에서 삭제하고 노트·부록으로 이동 |

모든 화면에 문장을 채울 필요는 없다. 자료가 없는 부분에 가짜 사내 화면이나 범용 서버 사진을 넣지 않았다. 지금 화면은 확인된 사실을 설명하는 글자·도식이며, 실제 행사 자료인 것처럼 꾸민 결과물이 아니다.

## 5. 모션 판단

장면마다 로고를 띄우거나 새 코너가 시작되는 효과를 넣으면 목록처럼 보인다. 대부분은 0.25초 안팎의 짧은 전환 뒤 정지한다. 별도 강조는 IAP의 기능에서 소개·실습으로 넘어갈 때, 녹화에서 교육 플랫폼 공유로 넘어갈 때만 쓴다.

PPTX에는 실제 애니메이션이 없다. 대본·노트의 발화 큐가 영상팀의 구현 기준이다. 숫자는 뛰어오르지 않고 완성 상태로 보인다. 자료를 읽는 동안 카메라·글자·선이 동시에 움직이지 않게 한다.

## 6. 아직 해결되지 않은 것

- 참여자 한 사람의 선택과 변화가 이어지는 경험담은 없다. 이번 안은 설득력 있는 설명을 목표로 하며 감동 서사를 확보했다고 평가하지 않는다.
- 실제 업무 소개 판넬, 과제 자료, 실습 사진, 교육 플랫폼 화면은 아직 없다. 그 자료가 들어오면 화면의 구체성이 가장 크게 좋아진다.
- 팀장과 교육담당의 의견 대사는 촬영용 제안이다. 본인의 말투와 생각에 맞춰 바꾸는 과정은 남아 있다.
- 글자만으로 최종 영상 5분 전체를 채우면 단조로울 수 있다. 인물 화면과 자료의 읽을 시간을 함께 편집하고 리허설에서 홀드를 조정해야 한다.

현재 종료 기준은 후보 탐색을 더 늘리는 것이 아니라 **새 제작본, 두 차례의 내용 검토, 실제 렌더 확인, 발화·큐·파일 검증, 기존 버전 보존**이다. 새로운 경험담이나 촬영 조건이 생기면 그 근거로 다시 판단한다.
