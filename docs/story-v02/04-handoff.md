이관우의 **사진 1·2는 아직 원본 파일을 받지 않았다.** IMG16·IMG17 영역은 사용자가 제공할 사진 자리다. 삽입 후 안내 글자·ID·테두리를 제거한다. 자료가 없는 장면은 같은 내용을 설명하는 키워드·도식과 인물 화면으로 편집한다. 가상 현장 사진이나 미확인 성과를 만들지 않는다.

실제 자료는 기본 PPTX를 복사해서 넣는다. 예를 들어 `learning-fair-2026-story-v02-1014-submission.pptx`는 제출 사본 이름 예시다. 자동 빌드는 기본 출력 파일을 다시 쓰므로 수동 삽입본은 별도 보관한다. 현재 PDF·PNG는 원본 삽입 전 제작본이다. 삽입 뒤 PDF도 다시 내보낸다.

## 촬영과 효과

팀장은 팀 역할·커지는 미션·교육의 의미를 말하고, 교육담당은 운영 방식과 본인의 경험을 보탠다. 팀장도 세미나 공유와 교류의 구체적인 내용을 짚는다. 서로 처음 듣는 듯한 반응이나 과거에 직접 지시했다는 회고를 추가하지 않는다. 이름·직함은 첫 개인 화면에 표시한다.

숫자와 제목은 완성형으로 띄운다. 본편 하단의 공통 진행표로 지금 다루는 학습 행동을 알려준다. 의미가 바뀔 때 현재 단계를 한 번 강조하고, 매 장표에 새 음악·코너 오프닝을 붙이지 않는다. IAP는 18초 안에 로그→지정 형식→메신저 알림만 강조한다. 사진과 선택 화면은 대사 위에 겹쳐 쓰고 별도 시간을 더하지 않는다. PPT에는 실제 애니메이션을 넣지 않았다.
