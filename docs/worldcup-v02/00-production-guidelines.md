# 월드컵형 제작 지침

> 이 문서에서 해야 할 일: 초안의 화면 구조와 아래 서사·사실·시간 기준으로 PPT·대본·콘티를 만들고 함께 검수한다. 이전 제작본은 보존하고 이 버전의 원본과 출력만 수정한다.

## 공통 이야기

팀 역할과 규모 → AI 4 AI 비전과 함께 성장할 필요 → 외부의 기술과 경험 → Tech X의 공동 참여와 이관우의 경험 → Job Fair·DCIS의 업무 이해 → 전체 교육문화와 팀 미션의 회수다. AI 인프라의 미션을 감당할 사람의 성장에 교류가 필요하다는 관계로 연결한다. 특정 행사가 다음 프로젝트를 낳았다는 인과나 연대기를 만들지 않는다.

화면은 초안의 네이비·민트·라일락, 설명하는 도식, 공통 진행표를 기준으로 한다. 짧고 자연스러운 제목과 실제 자료를 사용한다. 모든 제목을 기계적으로 명사형으로 줄이지 않는다. 부록을 제외한 장표에는 제작 지시를 큰 문구로 넣지 않는다.

## 새로 반영할 사실

- 사용자 확인: DS부문 임직원 7만 명 이상이 사용하는 모든 IT 인프라, 32개 DC, 100만 코어 이상의 컴퓨팅 자원, 회사 시스템 대부분이 운영되는 클라우드, GPU 기반 인프라의 제공·운영. 수치의 내부 증빙은 추후 삽입하며 외부에서 추정하지 않는다.
- AI 4 AI 공식 확장명은 Advanced Infrastructure for Artificial Intelligence다. AI를 위한 첨단 인프라라는 팀 비전과 실제 월례 외부 세미나의 의미를 구분해서 설명한다.
- Tech X는 각 파트의 과제 제시·3월 모집·지원자 선발·4월 착수, 다른 부서의 과제에 참여하는 문화다. 6개 과제·44명은 참여 규모다.
- 이관우는 관심으로 k8s GPU 자원 효율화 과제에 지원했고 다른 부서의 관점을 배웠다. 사진 1·2는 IMG16·IMG17 자리로 남긴다. 아직 파일은 받지 않았다. GPU 개선 수치나 구체적인 미제공 대화는 넣지 않는다.
- IAP는 사용자 새 지시에 따라 20초 이내의 짧은 Tech X 대표 사례로 사용한다. 서버 로그 패턴 감지·지정 형식의 메신저 알림·수작업 대체만 말한다. 전 인프라 적용 완료·정량 절감은 주장하지 않는다.
- Job Fair는 8월 11개 부서의 업무 소개, DCIS는 월례 과제·서비스·연구 공유다. 교류·원팀은 목적과 발표자의 관점으로 설명한다.

## 제작·검수

회사 인트로 5초 + AI 팀 소개 15초 + 본편 275초 + 회사 아웃트로 5초 = 300초다. P01–P10·S01–S10, 숨김 부록 A01–A03을 사용한다. 발화는 영문·숫자의 읽기와 호흡을 포함해 추정하고 실제 리허설과 구분한다. 사진 삽입과 자막·선 강조는 장면 안에 포함한다. PPT는 정적 편집 원본이며 실제 효과는 영상팀이 적용한다.

10월 11일 기준 OutSystems는 12일 예정, 제출 14일, Tech X 최종 발표 16일 예정, 촬영 19일이다. 확인되지 않은 발표·시상 결과를 미리 넣지 않는다. 실제 자료는 별도 PPTX 사본에 삽입한다.

원본은 content/worldcup-v02-film.json, 출력은 deliverables/worldcup-v02/다. 두 새 제작본은 scripts/build_story_pair.py로 생성하고 scripts/render_story_pair_slides.sh로 실제 PowerPoint PDF·PNG를 내보낸 뒤 scripts/validate_story_pair.py로 검수한다.
