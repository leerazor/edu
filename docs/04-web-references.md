# 외부 참고자료와 출처

> 이 문서에서 해야 할 일: 아래 공식 자료를 배경 참고로 사용하고, 외부 이미지의 출처·권리를 확인한다. 팀의 실제 활동과 내부 성과는 사용자 제공 사실·사내 원본으로 표현한다.

이전 조사에서 확인한 기술·학습문화 자료를 현재 두 제작본에 필요한 참고로 묶었다. **외부 사진은 현재 PPT에 삽입되지 않았으며 사내 사진의 대체 증빙이 아니다.** 방송·게임·유튜브 콘셉트 비교는 정리 대상에서 제거했다.
