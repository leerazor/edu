## 제작과 확인

2026-10-11까지 사용자 제공 사실. 이관우의 k8s GPU 과제 참여 경험은 본인 진술을 촬영용으로 다듬은 문장이다. 팀장의 교류 관점은 사용자 확인을 바탕으로 구성했다. 과거 발언의 녹취 인용·전체 구성원의 경험·GPU 효율 개선 실적을 뜻하지 않는다. 추가 사용자 지시: 도입에 DS부문 모든 인프라를 책임지고 AI로 운영도 효율화하는 팀 역할과 교류·성장의 교육문화 핵심을 먼저 제시한다. 인원 규모는 도입에서 강조하지 않는다.

실제 행사 사진·화면 원본은 사용자가 별도로 삽입한다. 장면별 asset_slots의 ID·자료명·교체 방법을 확인한다. 범용 외부 사진을 실제 사내 시설·행사 증거로 사용하지 않는다. 원본 수집과 사실 확인은 docs/03-facts-and-assets.md를 따른다.

## 사진 삽입용 제작본 사용 방법

이 PPTX는 사용자가 실제 사진·화면 원본을 나중에 붙이는 제작본이다. 점선 영역의 ‘자료 삽입’ 안내와 IMG ID는 교체할 편집 가능한 도형이다. 빈 삽입 영역을 최종 영상으로 그대로 사용하라는 뜻이 아니다. 최종 편집 전 해당 실제 자료를 삽입하고 안내 글자와 점선을 제거한다. 원본을 쓰지 않으면 영상팀이 같은 메시지의 키워드 화면으로 다시 구성한다.
