## 제작과 확인

2026-10-11 사용자 요청에 따라 공유 대화 마지막의 밸런스 게임 방향을 새로 구성했다. 실제 운영 사실은 docs/03-facts-and-assets.md 기준이다. 팀장님의 선택·의견은 촬영용 제안이며 과거 발언이나 확정된 취향이 아니다. GPU 과제 참여 경험과 IAP는 서로 다른 Tech X 과제다. 학습활동 전체와 개별 업무 변화 사례를 구분하며 미확인 효과·실적을 만들지 않는다.

PPTX는 정적 자료다. 등장·선택 강조와 자료 전환은 영상팀 편집 지시이며 장면 시간 안에서 구현한다. 숨김 부록 A01–A03은 본편에서 제외한다.

선택은 프로그램의 순위나 승패를 정하지 않는다. PRE / POST-A / POST-B는 같은 질문의 공개 상태다. 실제 선택에 맞는 대체 응답을 사용하고, 촬영 후 본문 대사·공개 큐·선택 화면을 함께 확정한다.

실제 사내 사진과 화면은 사용자가 넣는다. 기본 PPTX를 복사한 별도 제출 사본에 붙이고, 범용 외부 사진을 실제 팀 행사로 사용하지 않는다. 원본 번호는 docs/03-facts-and-assets.md를 따른다.

`content/balance-v03-film.json`를 수정한 뒤 `.venv/bin/python scripts/build_balance.py`로 다시 생성한다. 전달 지시는 `docs/balance-v03/04-handoff.md`를 따른다.
