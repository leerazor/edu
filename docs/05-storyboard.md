## 장면별 편집 지시

본편은 활동의 시간순 기록이 아닌 교육문화의 연결을 보여 준다. 성장 회로는 문화 모델이다. 특히 Job Fair가 Tech X를 발생시켰거나, 외부 세미나가 IAP의 직접 원인이었다는 인과를 표현하지 않는다.

### S01 · AI 시대, 무엇이 우리를 성장시킬까요?

- 자료 등장 발화: **‘우리는 서버와 클라우드를’** → P01.
- 화면·효과: P01 등장. ‘서버·클라우드 / AI 인프라 / 약 160명’ 키워드 순차 표시.
- 카메라: 인사 2인 풀샷 → 팀장님 정면 클로스업 → 발화 큐에서 장표와 인물 분할 화면
- 원본: 별도 사진 불필요.
- 지시: 질문 뒤 1초 호흡. 마지막 발화까지 P01을 유지하고 연결선 한 점을 켠다. S02의 자료 등장 큐에서 P02로 전환.

### S02 · AI를 위한 인프라, AI로 발전하는 운영

- 자료 등장 발화: **‘그 연결의 이름이’** → P02.
- 화면·효과: P02 등장. 공식 영문 확장명 하단 표시. ‘AI를 위한 인프라 제공’ 다음 ‘AI를 활용한 운영’ 순서로 양방향 강조.
- 카메라: 교육담당 클로스업 → P02 전체 화면 → 교육담당 측면샷
- 원본: 별도 사진 불필요.
- 지시: ‘두 방향’ 앞 짧은 호흡. 도식은 기술 구조가 아닌 역할 설명임.

- 추가 자료 큐 ‘AI로 인프라 운영을 발전시키는’: AI를 활용한 운영 문장과 되돌아오는 연결선 강조.

### S03 · 밖의 지식이 우리의 질문을 넓힙니다

- 자료 등장 발화: **‘삼월부터 매달’** → P03.
- 화면·효과: P03 등장. 내부 세미나 사진 또는 승인 포스터 표시. ‘월 1회 / 센터원 대상’ 표시.
- 카메라: 교육담당 정면 → 세미나 이미지 전체 화면 4~6초 → 교육담당 클로스업
- 원본: IMG02, IMG03.
- 지시: 대상 규모는 누적 참석자 수가 아님. 월별 개최 목록은 부록에만 배치.

### S04 · 부서 사이의 거리를 줄였습니다

- 자료 등장 발화: **‘Job Fair에서는’** → P04.
- 화면·효과: P04 등장. Job Fair 부스 사진 → DCIS 자료 순차 전환. ‘11개 부서 / 서로의 업무·과제·서비스’ 표시.
- 카메라: 팀장님 클로스업 → 2인 연결샷 → 교육담당 클로스업 → 장표 전체 화면
- 원본: IMG04, IMG05, IMG06.
- 지시: 발화자 교대에 1초 배정. 모든 팀원이 실제 참석했다는 숫자는 넣지 않음.

### S05 · 이해에서, 함께 해보는 경험으로

- 자료 등장 발화: **‘Tech X에서는’** → P05.
- 화면·효과: P05 등장. ‘6개 프로젝트 / 44명 참여’ 큰 숫자. 여러 부서에서 공동 프로젝트로 모이는 편집 가능한 연결 도식.
- 카메라: 교육담당 클로스업 → P05 전체 화면 → 2인 풀샷
- 원본: IMG07.
- 지시: 숫자는 현재 참여 현황. 프로젝트 완료 수·졸업 인원으로 표현하지 않음.

### S06 · IAP: 사람이 하던 알림 업무를 자동화

- 자료 등장 발화: **‘그중 한 프로젝트가’** → P06.
- 화면·효과: P06 등장. Tech X 과제 → 팀 주요 미션 → 운영 도입 표시. 서버 로그에서 특정 패턴을 감지하면에서 로그 패턴 감지 → 정형 메시지 → 메신저 동보 도식. 승인된 실제 IMG08 화면 삽입.
- 카메라: 류경동 팀장 정면 → IAP 실제 기능 도식 전체 화면 6~8초 → 승인 알림 화면 IMG08 → 류경동 팀장 측면샷
- 원본: IMG08.
- 지시: 자동 동보는 사용자 확인 운영 사례. 전 인프라 적용은 확대 목표. 절감시간·근본원인 분석·자동 복구를 추가로 주장하지 않음. 실제 화면이 없으면 기능 도식 유지.

- 추가 자료 큐 ‘서버 로그에서 특정 패턴을 감지하면’: 로그 패턴 감지 → 정형 메시지 → 메신저 동보 순차 표시. 실제 화면이 확보되면 여기서 5초 삽입.

### S07 · 만든 사람이, 함께 쓰는 사람에게

- 자료 등장 발화: **‘6월에는 IAP를’** → P07.
- 화면·효과: P07 등장. ‘6월 팀 소개 → 7월 실무 실습 / 25명’ 순차 표시. 실습 사진 IMG10.
- 카메라: 교육담당 클로스업 → 세미나·실습 자료 2컷 → 교육담당 정면
- 원본: IMG09, IMG10.
- 지시: 실습 후 전원 에이전트 등록 완료 또는 효과 실증으로 확대해 말하지 않음.

- 추가 자료 큐 ‘7월에는’: 7월 실습 사진 및 25명 표시.

### S08 · 경험은 현장에서도 전해집니다

- 자료 등장 발화: **‘명장님과 함께한’** → P08.
- 화면·효과: P08 등장. 내부 승인 투어 사진 IMG11·IMG12. ‘명장과 함께 / 현장에서 배우다 / 8명’ 표시.
- 카메라: 교육담당 정면 → 투어·서버 체험 사진 2컷 → 팀장님과 교육담당 2인샷
- 원본: IMG11, IMG12.
- 지시: 7월 행사. 앞 장면보다 이후 개최로 오해시키는 ‘이후’ 표현 금지. 외부 서버 사진으로 실제 센터를 대체하지 않음.

### S09 · 한 번의 배움을, 다음 사람의 출발점으로

- 자료 등장 발화: **‘외부 세미나는 녹화해’** → P09.
- 화면·효과: P09 등장. 승인 교육 플랫폼 화면 IMG13 → 배움·이해·실행·공유 연결 회로 완성. 하단 시작 제안: 교류 열기 → 공동 과제 → 다시 공유.
- 카메라: 팀장님 클로스업 → 교육 플랫폼 화면 → 연결 도식 전체 화면
- 원본: IMG13.
- 지시: 녹화·업로드가 확인된 범위는 AI 4 AI 외부 세미나. 타 조직 확산은 적용 가능성 제안이며 실제 확산 성과가 아님.

- 추가 자료 큐 ‘교류를 열고’: 교류 열기 → 작은 공동 과제 → 다시 공유 제안 표시.

### S10 · AI 4 AI — 연결이 성장의 인프라가 되다

- 자료 등장 발화: **‘AI를 위한 인프라를 만들고’** → P10.
- 화면·효과: P10 등장. ‘AI 4 AI / 연결이 성장의 인프라가 되다’ 타이틀. 마지막 인사에 2인 화면 복귀.
- 카메라: 팀장님 클로스업 → 교육담당 클로스업 → 2인 풀샷 → 타이틀 홀드
- 원본: 별도 사진 불필요.
- 지시: 두 사람의 동시 발화는 마지막 공동 발화 블록만. 04:55 회사 아웃트로로 컷.
