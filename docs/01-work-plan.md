## 실행 원칙

- Markdown 문서는 첫머리에 ‘이 문서에서 해야 할 일’을 기재한다.
- 편집 가능한 원본과 검토용 결과를 함께 저장한다.
- 초안에서 해결할 수 있는 작업은 진행하고, 사내 확인이 필요한 정보는 후속 확인 목록에 모은다.
- 사용자에게 실제 사진이 없다는 이유로 전체 작업을 멈추지 않는다. 사진 위치와 필요한 원본을 구체화한다.
- 외부 자료 조사는 콘셉트 검토와 병렬로 진행할 수 있다. 파일별 작업 범위를 구분해 충돌을 피한다.

## 현재 납품 상태 (2026-10-09)

콘셉트·사실·웹 출처·콘티·대본·PPTX·AI 소개 브리프·전달 문서·검수 패키지를 작성했다. 사용자 추가 답변의 실명, 평가 기준, 10월 개최 예정 상태, IAP 로그 알림 자동화 사례를 반영했다. 본편 10장과 참고 부록 3장의 PPTX를 Microsoft PowerPoint로 실제 렌더했다.

남은 제작 단계는 내부 사진·실제 화면 수급, 회사 KV 적용, 리허설 실측, AI 소개 영상 생성, 촬영·최종 편집이다. 모든 산출물을 GitHub `main`에 푸시했고 원격 커밋과 로컬 커밋이 일치함을 확인했다.

## 발표자 관점 후속 검토 (2026-10-10)

추상적인 도입, 프로그램별 나열, 두 화자의 교대 낭독을 검토했다. 사용자 피드백에 따라 IAP 중심으로 전개하던 검토 제안을 철회하고 **구성원의 교류와 학습문화**를 중심에 뒀다. 추천 방향은 **AI 4 AI — 배움이 부서를 넘을 때**다. 동료의 일에 대한 궁금증으로 시작해 서로의 업무·현장을 만나고, 함께 해보고, 배움을 나누는 구성이다.

6개 본편 구간에 275초를 배정했다. IAP는 Tech X 안의 대표 사례로 기능·소개·실습을 합쳐 약 40초를 제안하며, 명장 투어는 숙련자와 신규·복귀 구성원의 현장 교류를 보여 주는 자리에 둔다. 개정 대본의 발화량은 아직 계산하지 않았다.

효과도 업무 카드와 실제 교류 장면을 중심으로 수정했다. 기존 8초 IAP 모션 예시는 대표 사례 안의 기능 설명을 위한 보조 자료로 유지한다. 이번 수정은 지침·검토 문서에 반영했으며, 현재 촬영 대본·PPTX는 v0.1이다. 다음 정식 개정 때 원본 데이터부터 수정하고 대본·장표·큐를 함께 재생성한다.
