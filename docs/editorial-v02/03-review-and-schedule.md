# 실제 경험 반영과 제출 일정 검토

> 이 문서에서 해야 할 일: 새 대사가 제공된 경험을 넘어서지 않는지 확인하고, 10월 14일 제출본과 16일 이후 확인할 내용을 구분한다. 리허설에서는 장면 사이의 연결과 자료를 보는 시간을 함께 확인한다.

## 이번에 달라진 이야기

제목은 **AI 4 AI — 그 일, 같이 해볼까요?**를 유지한다. 진행 형식은 실제 자료를 보며 두 사람이 설명하는 공동 해설이다. 이관우 교육담당이 참여한 경험이 생겼으므로 별도 방송 설정을 덧붙일 필요가 줄었다.

서로의 일을 모르는 상황에서 시작해, 업무를 소개하고(Job Fair·DCIS), 직접 참여할 기회를 만들고(Tech X), 그 안에서 무엇을 배웠는지(이관우의 경험)를 듣는다. 이어 다른 과제의 운영 적용 사례(IAP)를 보여준다. 팀 밖 전문가에게 배우는 AI 4 AI와 녹화 공유를 거쳐, 다른 조직도 적용해 볼 운영 방식으로 끝낸다. 이 순서는 설명의 순서다. 8월 Job Fair 때문에 3월 Tech X가 생겼다는 인과는 주장하지 않는다.

| 검토한 문제 | v02에 적용한 수정 | 남아 있는 한계 |
| --- | --- | --- |
| ‘교류하며 성장했다’가 누구나 할 수 있는 말처럼 들림 | S05 40초에 본인이 지원한 k8s GPU 자원 효율화 과제와 다른 부서의 관점을 접한 경험을 배치 | 구체적인 의견 충돌·해결 장면은 제공되지 않아 만들지 않음 |
| IAP가 교육문화 전체를 대표하는 듯 보일 수 있음 | 개인 경험 다음에 ‘다른 과제’로 연결하고 S06 35초 유지 | GPU 과제와 IAP를 같은 과제로 편집하면 안 됨 |
| 팀장이 행사 소개에 동의만 하는 역할 | 결속·사기·원팀 문화와 다른 관점의 문제 해결을 중요하게 보는 이유를 직접 설명 | 측정된 조직문화 개선이나 과거 발언의 직접 인용은 아님 |
| Tech X를 타 조직이 어떻게 시작할지 모호함 | 3월 모집·4월 착수, 파트별 주제·지원·선발, 시간 할애와 우수 프로젝트 인정 방식을 반영 | 근무시간 안팎·할애 비율·시상일·수상 결과는 미확인 |
| 발표 자료가 추상적인 문장으로만 구성됨 | 본편 7장에 실제 자료 삽입 영역 9곳을 표시 | 원본은 사용자가 추후 삽입하므로 현재 화면은 배치 안내용 |

프로그램명은 여전히 여러 개 등장한다. 나열감을 줄이는 핵심은 장면마다 새 코너를 여는 효과를 넣지 않고, ‘소개 → 참여 → 개인의 배움 → 업무 적용’의 질문을 이어가는 것이다. 발표자는 프로그램명을 읽기보다 그 장면에서 달라지는 행동을 설명한다. 월드컵·기본본·공동 해설 v01은 비교용으로 보존했다.

## 일정에 따른 확정 범위

| 날짜 | 확인된 일정 | 해야 할 일 |
| --- | --- | --- |
| 10월 11일 | 현재 기준일 | 이번에 제공된 경험·운영 방식으로 v02 작성. 12일·16일은 예정으로 관리 |
| 10월 12일 | OutSystems 세미나 예정 | 실제 개최 여부와 최종 주제를 확인한 뒤 필요할 경우 포스터·행사 자료 추가. 현재 본편에는 개최 완료 주장 없음 |
| 10월 14일 | 자료 제출 | PPT·대본·콘티를 같은 버전으로 전달. 16일 최종 발표 결과나 미확인 수상 결과를 미리 넣지 않음 |
| 10월 16일 | Tech X 최종 발표 예정 | 실제 확인한 결과가 있으면 변경 장면·문구·이미지만 정리해 영상팀과 반영 범위 조율. 최종 발표를 프로젝트 완료나 시상일로 간주하지 않음 |
| 10월 19일 | 촬영 | 최종 대본 버전을 맞추고 낭독·자료 큐 확인. 16일 이후 새 결과가 없어도 현재 확인된 사례로 촬영 가능 |

자료 전달 뒤 영상팀이 편집하므로 날짜가 지났다는 이유만으로 파일을 일괄 수정하지 않는다. 확인 후 변경이 생기면 버전과 변경 장면을 표시한다. 이 문서는 일정 관리 기준이며 자동 후속 작업 예약은 아니다.

## 검토와 남은 확인

별도 검토에서 3월 모집·4월 착수, 개인 경험과 IAP의 구분, 팀장 관점과 측정 성과의 구분, 미래 일정의 시제에 차단할 문제는 발견되지 않았다. 실제 PowerPoint 화면을 확인해 P02·P07의 좁은 항목명을 줄이고 P03의 줄바꿈을 정리했다.

전체 배정은 300초이며, 고정 영상 25초와 본편 275초다. 대본은 발음 환산 926음절이다. 호흡을 포함한 느린 발화 추정은 본편 약 239초, 고정 영상 포함 약 264초다. 여유 시간은 자료 확인·화자 교대 등에 사용하되, 빈 화면을 오래 유지해 5분을 채우지 않는다. 최종 5분 편집은 실제 리허설과 영상팀 편집으로 확인한다.

실측 리허설과 내부 원본 삽입은 남아 있다. [검증 보고서](../../deliverables/editorial-v02/validation-report.json)는 원본·대본·큐·PPT·실제 렌더 일치와 기존 제작 파일 104개의 보존을 확인한다. 이 검증이 출연자 낭독이나 내부 이미지 검토를 대신하지는 않는다.
