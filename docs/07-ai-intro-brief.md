# 15초 AI 팀 소개 영상 제작 브리프

> 이 문서에서 해야 할 일: AI 제작 담당에게 15초의 역할·컷·화면·자막·연결 조건을 전달한다. 회사 인트로와 본편 사이에 삽입하고, 최종 생성 결과의 길이·텍스트·실사 오인 여부를 검토한다.

**확인 수준:** 사용자 제작 조건에 맞춘 화면 설계 초안이다. 실제 AI 영상은 이 패키지에서 생성하지 않았다. 회사 KV·로고·폰트·음악·최종 출력 규격은 미수급이다.

**추천 타이틀:** AI 4 AI — 연결이 성장의 인프라가 되다. 회사 KV 수급 전 색감은 차콜·민트·라일락을 참고하며, 최종 영상에서는 공식 KV로 교체한다.

## 1. 역할과 배치

- 전체 영상의 **00:05~00:20**, 총 15초. 회사 제공 인트로 5초 직후, 스튜디오 발표 시작 직전에 삽입한다.
- Data Center팀을 “AI를 위한 인프라를 제공하고, AI를 활용해 운영을 발전시키는 팀”으로 소개한다.
- 시설 → AI의 양방향 역할 → 사람의 교류로 이어진다. 기술을 소개하는 장면이 교육문화의 시작과 자연스럽게 연결되도록 한다.
- **내레이션 없이 음악·그래픽·편집 자막으로 구성**한다. 본편의 팀장님·교육담당 발화는 00:20부터 시작한다. 추가 내레이션을 넣을 경우 본편 발화와 겹치지 않도록 영상팀과 재조정한다.
- 본편 출연자는 **류경동 팀장·이관우 교육담당**이다. 이 15초에는 인물 소개를 추가하지 않고, 본편의 실질적 성과(IAP)와 확산 가능한 교류 방식(Tech X)을 소개할 시각적 바탕을 만든다. 실제 타 조직 확산이 완료된 모습으로 묘사하지 않는다.

## 2. 세 컷 구성

| 컷 | 전체 타임코드 / 컷 길이 | 화면 | 편집 자막 | 전환·본편 연결 |
| --- | --- | --- | --- | --- |
| AI-01 | 00:05~00:10 / 5초 | 추상화된 서버·연산 노드가 켜지고 서로 연결된다. 데이터가 이동하는 빛으로 인프라의 역할을 표현한다. 실제 시설 설계·제품과 다른 상징적 그래픽. | `Data Center팀` / `AI를 위한 인프라` | 회사 인트로 종료 후 명확히 시작. 마지막 연결선이 다음 컷의 두 방향 선으로 확장. |
| AI-02 | 00:10~00:15 / 5초 | 중앙의 인프라 형상과 AI 연산 형상 사이에 두 방향의 흐름이 생긴다. 하나는 AI 활용을 뒷받침하는 인프라, 다른 하나는 운영에 활용되는 AI를 뜻한다. | `AI를 위한 인프라` ↔ `AI를 활용하는 운영` | 양방향 흐름을 짧게 보여 준 뒤 선이 사람·지식의 연결로 이어짐. 실제 IAP 기능 화면을 흉내 내지 않음. |
| AI-03 | 00:15~00:20 / 5초 | 여러 사람을 상징하는 노드가 서로 지식을 주고받고 하나의 연결된 구조를 만든다. 마지막에는 중앙 여백을 남겨 타이틀을 넣는다. | `AI 4 AI` / `연결이 성장의 인프라가 되다` | 마지막 0.5~1초는 읽을 수 있게 안정된 화면 유지. 같은 연결선·색·타이틀을 P01에 이어 쓰고 00:20 스튜디오 화면으로 전환. |

위 5초씩은 편집 목표 길이다. 생성 모델이 정확히 5초를 지원하지 않으면 충분한 길이로 생성한 뒤 각각 5초로 편집한다. 원본 클립 전체 길이를 그대로 합쳐 15초를 넘기지 않는다.

## 3. 생성용 프롬프트 초안

각 컷을 별도로 생성하고 편집에서 연결한다. 모든 컷은 16:9, 동일한 시각 스타일·색상·빛의 방향을 유지한다. 아래 프롬프트의 배경색·강조색은 회사 KV 수급 후 교체한다.

### 공통 스타일

```text
16:9 기업 발표 영상용 모션 그래픽. 추상적인 데이터센터 인프라와 사람·지식의 연결을 간결하게 표현한다. 기하학적 3D 형상, 절제된 빛과 움직임. 차콜 배경, 민트 중심 강조색과 소량의 라일락 보조색을 사용하되 회사 KV 수급 후 공식 색으로 교체한다. 시청자가 5초 안에 의미를 이해할 수 있는 단순한 구도. 전문적이고 차분한 분위기. 카메라 움직임은 느리고 안정적이다. 화면 중앙과 하단에는 편집 자막을 넣을 충분한 여백을 둔다. 실제 회사 시설·서버 제품·인물의 재현이 아니라 상징적인 그래픽이다. 화면 안에 글자·숫자·브랜드 로고·워터마크를 생성하지 않는다.
```

### AI-01: AI를 뒷받침하는 인프라

```text
서버를 상징하는 단순한 세로형 연산 블록들이 차례로 켜진다. 작은 빛의 점들이 블록 사이를 연결하고 안정적인 네트워크를 이룬다. AI의 연산과 활용을 받쳐 주는 인프라를 표현한다. 실제 데이터센터 내부 사진처럼 만들지 않는다. 과장된 시설 규모나 특정 제조사의 제품을 묘사하지 않는다. 마지막에는 연결선 하나가 화면 중앙으로 부드럽게 이동해 다음 컷과 연결될 수 있게 한다. 5초 편집에 적합한 한 가지 동작만 사용한다.
```

### AI-02: AI와 인프라 운영의 두 방향

```text
왼쪽에는 서버를 상징하는 간결한 블록, 오른쪽에는 AI 연산을 상징하는 추상적인 노드 구조가 있다. 두 형상 사이를 빛의 흐름이 서로 다른 방향으로 이동한다. 인프라가 AI 활용을 뒷받침하고, AI가 다시 인프라 운영에 활용되는 관계를 표현한다. 실제 소프트웨어 UI·대시보드·성능 수치는 만들지 않는다. 마지막에는 두 방향의 선이 여러 작은 노드로 이어진다. 5초 편집에 적합한 명료한 움직임.
```

### AI-03: 사람과 지식의 교류

```text
여러 사람을 상징하는 단순한 노드들이 나타난다. 지식을 상징하는 작은 빛이 노드 사이를 오가면서 연결이 넓어진다. 다양한 역할의 사람이 서로 배우고 함께 실행하는 느낌을 표현한다. 인물 얼굴·실제 직원·실제 행사 사진은 만들지 않는다. 연결된 형태가 마지막에는 안정된 구도로 정리되고 중앙에 타이틀을 넣을 여백이 생긴다. 마지막 1초는 거의 움직이지 않아 편집 자막을 읽기 쉽게 한다. 5초 편집에 적합한 구성.
```

**편집에서 추가할 문자:** AI 4 AI, Data Center팀, 한글 자막, 필요 시 승인된 회사 로고. 생성 영상 안에서 글자를 만들지 않는다. 영문 확장명은 15초 화면에 길게 넣기보다 P02에서 정확하게 소개한다.

## 5. 검토 체크

- [ ] 회사 인트로 뒤 00:05에 시작하고 본편 직전 00:20에 끝난다.
- [ ] 세 컷의 합계가 15초이며 300초 전체 구성과 맞는다.
- [ ] ‘AI를 위한 인프라’와 ‘AI를 활용하는 운영’의 두 방향이 읽힌다.
- [ ] 마지막 컷이 사람의 교류와 성장으로 연결된다.
- [ ] 타이틀·한글·로고는 편집 자막이며 오탈자가 없다.
- [ ] 생성 시설이 실제 센터로 오인될 수 있는 명칭·실사 설명이 없다.
- [ ] 회사 KV·폰트·음원·원본 사용 조건을 확인했다.
- [ ] 본편 발화와 음악·추가 음성이 겹치지 않는다.
