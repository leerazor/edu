# v05 문구 교정 기록

> 이 문서에서 해야 할 일: 아래 전후 비교를 읽고 화면 제목과 실제 발화를 따로 검토한다. 리허설에서는 입에 걸리는 표현을 표시하고, 대사 변경은 v05 원본에 반영한다.

## 교정 방향

기존 자료는 화면 제목에 이유와 결론을 한꺼번에 넣었다. 상단 설명·큰 제목·대본에도 같은 뜻이 반복됐다. 이번에는 상단을 프로그램명으로 줄이고, 큰 제목은 한눈에 읽히는 내용으로 바꿨다. 이유와 경험은 대본에서 설명한다.

부제는 **함께 쌓는 전문성**이다. AI 4 AI와 교류의 관계를 한 문장의 슬로건에 모두 넣으려 하지 않고, 팀의 역할·외부 세미나·본인 경험·운영 사례로 설명한다.

## 보조 문구와 단어

- 상단의 긴 해설을 프로그램명 또는 짧은 구분으로 교체했다. 예: ‘다른 전문성을 가진 동료와 함께 해보다’ → ‘Tech X’.
- 참여 규모·시기·대상처럼 확인된 사실만 보조 문구로 남겼다. 제목과 같은 뜻의 항목은 삭제했다.
- ‘AI 지원과 활용을 위해’, ‘기술의 방향’, ‘전문성을 교류하다’ 같은 표현을 실제 업무·기술·경험을 가리키는 말로 바꿨다.
- ‘판넬’ 표기를 ‘패널’로 정리했다. IAP 기능은 ‘패턴 감지 → 메신저 알림’과 ‘지정 형식으로 자동 전송’으로 표시했다.
- 사진 자리도 ‘실제 IAP 알림 화면’, ‘7월 실습 사진 또는 교안’, ‘교육 플랫폼 녹화 영상 화면’처럼 붙일 자료가 바로 드러나게 썼다.

## 대본과 사실 확인

대본은 장표 문구를 그대로 읽지 않는다. 팀장님은 팀이 하는 일과 교육에 대한 생각을, 교육담당은 운영 방식과 본인 경험을 설명한다. 형식적인 동의·유도 질문과 추상적인 연결 문장을 줄인다.

이관우의 GPU 과제 경험과 다른 과제인 IAP는 구분한다. IAP는 35초다. 전체 인프라의 AI 적용 완료, GPU 성능 개선 수치, 시상 결과는 추가하지 않는다. Job Fair·DCIS를 AI 전용 교육으로 바꾸지 않는다.

외부 전문가와 동료에게 배우는 이유, 함께 일하며 얻은 관점, 소개·실습·녹화로 나누는 방식은 유지한다. 문구를 줄이면서 교육문화의 근거까지 생략하지 않는다.

## 검수와 남은 확인

본문 10장 전체의 제목·상단·보조 문구·자료 자리, 숨김 부록 3장의 제목·표현을 검토한다. 발화와 자료 큐·PPT 노트는 원본에서 함께 생성한다. 실제 PowerPoint 화면에서 줄바꿈·가독성·불필요한 중복을 확인한다.

문구의 자연스러움은 글자 수만으로 판단하지 않는다. 출연자 리허설에서 말하기 편한 표현과 호흡을 최종 확인한다. [검증 보고서](../../deliverables/editorial-v05/validation-report.json)는 파일·큐·시간 추정·실제 렌더·이전 제작본 보존을 확인한다.


## 이번 제작본 확인 결과

실제 Microsoft PowerPoint로 13장을 PDF·PNG로 내보냈다. 전체 미리보기와 일정 부록의 네 행을 눈으로 확인했으며, 텍스트 누락·영역 밖 배치 검사도 통과했다. 300초 배정, IAP 35초, 실제 자료 자리 9곳을 유지했다. 이전 제작 파일 194개의 해시가 보존 기준과 일치한다.

대본은 발음 환산 946음절이다. 느린 발화와 기본 호흡은 본편 약 244초로 추정하며, 고정 영상 25초를 더하면 약 269초다. 남은 시간은 자료를 보는 여유와 전환에 배정한다. 실제 출연자의 속도는 아직 측정하지 않았다.

별도 읽기 검토에서 화면의 설명문·당위형 표현이 줄고, 팀 역할→개인 교류 경험→전문성의 연결이 유지됨을 확인했다. 부제 자체는 넓은 표현이므로 실제 참여 경험과 자료가 구체성을 맡는다. 리허설에서 도입의 정보량과 두 사람의 말투를 한 번 더 확인한다.
