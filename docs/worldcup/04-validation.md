# 월드컵 추가본 검수 기록

> 이 문서에서 해야 할 일: 이번 검수의 범위와 남은 촬영 준비를 구분해 확인한다. 원본 대본이나 장표를 수정하면 빌드·PowerPoint 렌더·검증을 다시 실행하고 이 기록을 갱신한다.

**검수일:** 2026-10-10. **대상:** worldcup-v0.1. 기존 기본본은 변경하지 않았다. 결과는 `deliverables/worldcup/validation-report.json`과 `timing-report.json`에서 확인한다.

## 확인 결과

- `scripts/build_worldcup_package.py`로 본편 10장·숨김 부록 3장의 PPTX, 콘티·대본·발표자 노트·프롬프터·리허설 표를 같은 원본에서 생성했다.
- Windows Microsoft PowerPoint로 본편 자료 13장과 별도 결승 상태 자료 2장을 실제 PDF 및 1600×900 PNG로 내보냈다.
- `scripts/validate_worldcup_package.py` 결과 **PASS**, **1,772개 검사 통과**, 오류·미생성 필수 파일 없음. 이 수는 파일·도형·문자·자료 대응 검사의 합계이며 시청자 평가나 교육 성과 지표가 아니다.
- 실제 렌더의 전체 컨택트시트와 대진표·IAP 도식·결승 선택 전후 화면을 직접 확인했다. 후보명·화살표·한글·현재/목표 구분을 읽을 수 있으며, 결승 결과와 선택 이유는 선택 후 화면에서 공개된다.
- 4강의 네 후보, 두 진출자, 결승 Tech X 추천이 원본 메타·발화·자료와 일치한다. 결과는 촬영용 선택안으로 표시했다.
- 두 사람이 추천 이유를 주고받고 팀장이 학습의 현업 활용을 묻도록 구성했다. 교육담당의 세미나 추천과 팀장의 Job Fair 추천을 첫 경기에서 보여 준다.

| 항목 | 결과 | 해석 |
| --- | ---: | --- |
| 최종 목표 | 300초 | 회사 인트로 5 + AI 소개 15 + 본편 275 + 회사 아웃트로 5 |

| 느린 발화·호흡 추정 | 247.09초 | 초당 4.2음절 가정, 본편 자료·선택 홀드에 약 28초 여유 |
| 기준 발화·호흡 추정 | 227.69초 | 초당 4.6음절 가정 |

| IAP S06 | 배정 40초 / 느린 추정 35.86초 | 기능·현재 적용·소개·실습·확대 목표를 한 장면에 포함 |
| 리허설 실측 | 0개 장면 | 아직 실제 낭독을 측정하지 않음 |

모든 장면의 느린 추정이 배정 시간 안에 들어간다. 추정 발화가 끝난 뒤 별도 효과를 더하는 방식이 아니라, 반응·선택·자료 화면의 길이를 각 장면 안에서 조정해 5분을 맞춘다. 고정 영상까지 포함한 느린 추정은 272.09초이며 10분 상한 이내다.

## 후속 제작

1. 두 출연자가 촬영용 선택과 이유를 검토하고 장면별 실측을 `deliverables/worldcup/rehearsal.csv`에 기록한다.
2. 실제 내부 사진·IAP 기능 화면·회사 KV를 수급해 반영한다. 현재 본편은 키워드와 사실에 근거한 도식으로 구성돼 있다.
3. 10월 OutSystems 개최 여부는 마지막 확인 시 미개최·촬영 전 예정 상태다. 실제 개최 확인 후에만 부록 상태를 갱신한다.
4. 영상팀은 정적 PPTX와 발화 큐를 바탕으로 진출선 강조·화면 전환을 구현한다. 실제 PPTX 애니메이션이나 완성된 영상 파일은 이 검수의 대상이 아니다.
5. AI 팀 소개는 기존 브리프에 월드컵용 마지막 자막을 반영해 별도로 제작한다. 회사 고정 영상과 합친 최종 300초는 전문 촬영·편집 후 다시 확인한다.
