# 유튜브 13개 후보와 설정 없는 설명형 비교

> 이 문서에서 해야 할 일: 후보의 유명세보다 진행 원리·제작 조건·자료 요구량을 비교한다. 전체 형식을 가져올지, 일부 장치만 참고할지 구분하고, 마지막의 재검토 질문을 이용해 상담형과 설정 없는 설명형도 같은 기준으로 판단한다. 기존 PPT·대본·콘티는 수정하지 않는다.

조사일: 2026-10-11. 사용자 요청에 따라 **비교 조사부터 main에 기록한 후 최종 방향을 별도로 재검토**한다. 이 문서는 그 첫 단계다.

## 1. 이번 비교의 기준

최종 300초 = 회사 오프닝 5초 + AI 팀 소개 15초 + 두 사람의 본편 275초 + 회사 클로징 5초. 출연자는 류경동 팀장과 이관우 교육담당이며, 주 촬영은 정적 스튜디오다. 모든 교육 프로그램을 넣을 필요는 없다.

핵심은 AI 4 AI와 교류하며 성장하는 학습문화다. IAP는 실질 성과를 보여주는 대표 사례 하나로 한정한다. 현재 확인된 성과는 로그 패턴 감지·정해진 형식의 메신저 동보를 통한 해당 수작업 대체, 운영 도입, 소개·실습 등이다. 개선율·참여자 후기·프로그램 사이의 직접 인과는 만들지 않는다. 사실은 [03 사실 기준](03-facts-and-assets.md)에 따른다.

| 판단 기준 | 비교할 내용 |
| --- | --- |
| 이야기의 연결 | 다음 장면을 보게 하는 이유가 있는가? 단지 질문이나 프로그램 이름만 바뀌는가? |
| 출연자 적합성 | 두 사람이 실제 역할로 말할 수 있는가? 즉흥 개그, 처음 듣는 척, 가상 고민 연기가 필요한가? |
| 사실과 자료 | 지금 제공된 사실로 성립하는가? 추가 인터뷰·현장 체험·촬영 없이는 핵심이 사라지는가? |
| 시간 | 진행 규칙을 설명하는 데 시간을 쓰는가? 긴 대화에서 재미있는 부분을 골라야 하는가? |
| 평가 메시지 | 학습문화·실제 적용·타 조직의 시작 가능성이 함께 남는가? 기술 제품 소개로 기우는가? |
| 형식의 추가 가치 | 형식 이름을 지웠을 때보다 이해·기억·관심 중 무엇이 더 좋아지는가? |

점수·조회수로 순위를 계산하지 않는다. 아래 적합성은 이 제작 조건에 대한 편집 판단이며, 시청자 실험 결과가 아니다.

## 2. 확인 방법과 한계

공식 제작사·채널·영상 페이지의 소개, 검색 색인에 노출된 공식 영상의 제목·설명·챕터, 공개된 인터뷰와 영상 대본을 확인했다. **동영상 자체를 재생해 시청한 분석은 아니다.** 따라서 표정·실제 컷 길이·웃음 타이밍·음악 효과를 확인했다고 쓰지 않는다. YouTube 페이지 추출이 제한된 사례는 색인 확인 범위를 표시했다.

국내 9개와 해외 4개를 후보로 삼았다. 같은 계열인 핑계고·나불나불·살롱드립, 워크맨·전과자는 공통점과 차용할 장치를 구분했다. 13개 모두가 서로 다른 서사 구조라는 뜻은 아니다. 현재 인기순위나 수치는 비교하지 않는다.

## 4. 기존 추천과 기준안도 함께 비교

| 비교안 | 형식이 더하는 것 | 추가로 필요한 것·비용 | 다음 검토에서 확인할 것 |
| --- | --- | --- | --- |
| 기존 **배움 상담소** | 한 가지 고민을 유지하는 명분과 화면 정체성 | 상담 설정·질문 카드·처방 역할. 실제 사연은 없으며, ‘배워도 되나요’는 허가 문제처럼 들릴 수 있음 | 같은 연결을 상담소 이름 없이도 만들 수 있다면, 설정을 유지할 이유가 있는가? |
| **자료를 함께 보는 2인 해설** | 자료의 구체적인 내용이 다음 질문을 만듦 | 핵심 자료 선정, 두 사람의 의견 차이보다 관점의 보완 설계 | 자료가 실제로 논점을 진전시키는가, 행사 사진을 배경으로만 쓰는가? |
| **별도 설정 없는 설명** | 교육의 필요와 실제 활동에 바로 진입 | 문장 연결과 화면 편집으로 리듬을 만들어야 함 | 교대 낭독이나 ‘첫째·둘째·셋째’ 목록이 되지 않게 할 논리가 있는가? |

월드컵·티어메이커는 이번에 다시 채택하려는 후보로 두지 않는다. 기존 제작본과 [흐름 검토](worldcup/05-storyline-review.md)는 보존한다.

## 5. 전체 포맷보다 차용 가치가 큰 장치

아래는 원작의 대사가 아니라 이 프로젝트를 위한 예시다.

1. **알고 있는 사실에서 의미를 묻기 — 문명특급 참고.** ‘Job Fair가 무엇인가요?’보다 ‘11개 부서가 자기 일을 소개한 자리였죠. 동료의 일을 알아볼 접점을 만든 거군요’로 들어간다. 팀장이 처음 듣는 척할 필요가 없다.
2. **운영을 구체적으로 묻기 — EO 참고.** ‘교류가 중요합니다’ 다음에는 ‘본래 부서에서 하기 어려운 일을 어떻게 경험하게 했나요?’를 둔다. 구호 뒤에 사실이 나와야 한다.
3. **앞 답변을 다음 질문의 재료로 쓰기 — 자체 대화 장치.** ‘운영에 쓰였다는 말씀인데, 사용할 동료들이 직접 익히는 시간도 있었나요?’로 IAP의 소개·실습을 연결한다. 독립된 질문 카드를 새로 시작하지 않는다.
4. **화면이 말에 정보를 보태게 하기 — Vox 제작자 인터뷰 참고.** 참여 규모는 짧은 자막으로, 교류 방식은 실제 패널·공지·실습 자료의 구체적인 부분으로 보여준다. 모든 문장을 그대로 화면에 다시 쓰지 않는다. [제작자 인터뷰](https://www.pressclubinstitute.org/2026/07/21/vox-video-producer-nate-krieger-on-how-to-create-engaging-visual-journalism/)

이는 네 채널의 로고·세트·말투를 섞은 새 예능을 만들자는 제안이 아니다. 현재 제작 범위에 추가 가능한 문장과 자료 사용의 선택지다.

## 6. Git 기록 후 실시할 재검토

같은 사실을 넣은 상담형·자료 해설형·설명형의 짧은 도입을 작성하고 비교한다. 실제 시청자 실험이나 낭독 실측으로 부르지 않는다.

- 설정을 설명하는 문장을 빼면 중요한 내용이 더 빨리 나오는가?
- 두 사람이 이미 알고 있는 것을 모르는 척해야 하는가?
- Job Fair와 Tech X 사이에 실제 없던 인과를 넣지 않아도 연결되는가?
- IAP 장면을 덜어내도 영상의 중심이 교류와 학습문화로 유지되는가?
- AI 4 AI가 표지에만 남지 않고 실제 외부 세미나·녹화 공유와 연결되는가?
- 끝에서 프로그램 목록을 복창하지 않고, 다른 조직이 시도할 행동 하나를 남길 수 있는가?

**현재 단계의 결론:** 전체 형식을 그대로 가져올 후보보다 질문·자료·설명 장치를 참고할 후보가 많다. 문명특급·EO·Vox의 장치를 우선 검토하되, 별도 설정 없는 설명형을 동등한 기준안으로 놓고 최종 판단한다.
