# 월드컵 버전 영상팀 전달과 촬영 준비

> 이 문서에서 해야 할 일: 월드컵 전용 콘티·대본·장표를 읽고, 출연자 선택 이유와 대진표를 맞춘다. 내부 원본을 수집하고 리허설 실측·회사 디자인을 반영해 촬영·편집용 버전을 확정한다.

**상태:** 2026-10-10 검토용 추가 버전의 전달 지침. 생성·검수 상태는 실제 산출물과 `deliverables/worldcup/validation-report.json`에서 확인한다. 이 문서 자체는 검증 완료 보고가 아니며 영상팀에 별도로 발송하지 않았다. 실제 촬영본·AI 소개 영상은 제작 대상이다.

## 2. 선택형 진행의 의미

공통 질문은 **“다른 조직에 권하고 싶은 교류 방식은?”**이다. 4강의 두 비교와 결승을 통해 교육문화의 서로 다른 강점을 설명한다.

| 진행 | 촬영용 구성안 | 선택 이유의 방향 |
| --- | --- | --- |
| 4강 1 | AI 4 AI 세미나 vs Job Fair → Job Fair | 외부의 시야를 배우는 것과 동료의 업무를 이해하는 것의 차이. 다른 부서와 대화할 접점의 효용 설명 |
| 4강 2 | 명장 투어 vs Tech X → Tech X | 현장 경험을 배우는 것과 부서 밖의 과제를 함께 해보는 것의 차이. 지속적인 교류·공동 경험 설명 |
| 결승 | Job Fair vs Tech X → Tech X | 서로를 아는 기회에서 함께 해보는 기회로 확장할 수 있는 방식 제안 |

이 대진의 결과는 **실제 투표·출연자의 확정된 선호·팀 공식 평가가 아닌 촬영용 선택안**이다. 리허설에서 출연자의 실제 의견이 달라지면 원본 JSON의 발화와 진출 상태를 함께 바꾸고 장표·대본을 재생성한다. 선택하지 않은 활동도 장점과 교류 방식이 남도록 편집한다. 선택 이유를 위해 미제공 효과·후기를 창작하지 않는다.

**형식의 이점:** 매번 같은 질문으로 후보를 비교하므로 시청자가 흐름을 따라가기 쉽고, 두 사람의 선택 이유를 통해 교류의 효용을 설명할 수 있다. 실제 행사 화면은 이 설명을 뒷받침한다.

**조절할 지점:** 선택 반응·효과음·진출 화면이 길어지면 교육문화 설명 시간이 줄어든다. ‘최고의 프로그램’을 평가하는 인상이나 탈락 활동을 폄하하는 인상을 피하고, 다른 조직에서 참고할 수 있는 방식이라는 질문을 유지한다. IAP가 독립 후보처럼 보이거나 결승 전체가 IAP 개발 이야기로 바뀌지 않도록 한다.

## 3. 길이·출연·현장 구현

- 회사 인트로 **00:00~00:05**, AI 소개 **00:05~00:20**, 2인 스튜디오 본편 **00:20~04:55**, 회사 아웃트로 **04:55~05:00**. 전체 300초, 고정 25초, 본편 275초.
- 류경동 팀장은 교류 방식이 왜 유용한지, 현업에서 어떻게 활용할 수 있는지 질문하고 선택 이유도 설명한다. 이관우 교육담당은 프로그램의 실제 방식·경험·수치를 설명하고 비교한다. 말의 역할은 교대 가능하며 팀장에게 승자 발표만 맡기지 않는다.
- 기본 촬영은 2인샷과 개별 정면이다. 짧은 상대 반응은 같은 장면 안에 담고, 효과에 맞춘 연기·과장된 리액션·별도 콩트를 요구하지 않는다.
- 자료·진출선은 실제 발화 큐에 맞춰 후반 편집한다. 출연자는 점등이나 효과음이 끝날 때까지 기다리지 않는다.
- **PPTX에는 네이티브 애니메이션을 넣지 않는 제작 범위다.** 문서·발표자 노트의 후보 공개·선택·진출선 지시는 전문 영상팀의 편집 큐다.
- 짧은 선택 효과음·후보 강조는 발화와 충돌하지 않게 장면 안에 넣는다. 추가 카운트다운·환호·홀드를 별도 러닝타임으로 더하지 않는다. 선택하지 않은 후보는 글자와 색이 읽히는 상태로 유지하며 흑백 낙인·폭발·조롱 효과를 쓰지 않는다.

**15초 AI 소개의 월드컵용 변경점:** 기존 `docs/07-ai-intro-brief.md`를 제작 기준으로 재사용하되 AI-01·AI-02의 공통 구성을 유지한다. AI-03의 편집 자막은 기존 ‘AI 4 AI / 연결이 성장의 인프라가 되다’ 대신 **‘AI 4 AI / 우리 팀 배움 월드컵’**으로 넣고 마지막 화면을 월드컵 **P01**에 연결한다. 공식 확장명 `Advanced Infrastructure for Artificial Intelligence`는 이 버전의 **P01·P10**과 세미나 비교 장표 **P03 하단**에 표시하며, 기존 브리프의 P02 지시를 그대로 적용하지 않는다. 생성 영상 안에 문자를 만들지 않고 편집에서 자막을 넣는다. 배치와 길이는 00:05~00:20의 15초로 유지하며, 실제 AI 영상 파일은 아직 없다.

**결승 선택 전·후의 자료 큐:** 본편 P08은 선택을 마친 완성 상태다. 첫 ‘결승입니다. Job Fair 대 Tech X’ 큐에서는 `deliverables/worldcup/choice-preview/slide-01.png` 또는 `choice-states.pptx` 1쪽의 **선택 전 화면**을 사용한다. 두 후보를 같은 크기로 보여 주고 최종 승자는 숨긴다. ‘저는 Tech X입니다’에서 `choice-preview/slide-02.png` 또는 2쪽의 **선택 후 화면**으로 교체하며 최종 추천을 공개한다. 이후 본편 P08의 완성 화면을 사용할 수 있다. 두 상태는 별도 편집 자료이며 본편 장면을 추가하는 것이 아니다. 전환·선택 호흡·홀드는 기존 결승 24초 안에 포함한다.

## 4. Tech X 대표 사례 IAP: 한 장·40초

IAP는 교육문화의 대표 실질 성과를 보여 주는 **Tech X 설명의 한 사례**다. 별도 후보·개발 과정의 주인공·결승의 독립 평가 대상으로 만들지 않는다.

| 발화 내용 | 편집할 화면 |
| --- | --- |
| 서버 로그의 특정 패턴을 감지하면 정해진 포맷으로 메신저에 동보 | `로그 패턴 감지 → 정형 메시지 → 메신저 동보` 고정 도식에서 해당 단계만 순서대로 강조 |
| 기존에 사람이 하던 일을 대체한 실제 사례 | 승인된 IMG08 실제 화면이 있으면 발화 중 짧게 삽입. 없으면 기능 도식 유지 |
| 6월 팀 소개, 7월 실무 담당자 25명 실습 | 같은 장 안의 `6월 소개 / 7월 25명 실습` 문구 또는 IMG09·IMG10 실제 자료 |
| 인프라 전반으로 넓히려는 방향 | 확대 **목표**로 표시. 현재 전 영역 적용 완료로 바꾸지 않음 |

위 내용과 사진 전환·호흡은 40초 안에 포함한다. 사진이나 기능 화면의 노출 시간을 발화 뒤에 추가하지 않는다. IAP 화면이 아직 없으므로 사실에 맞는 도식을 기본안으로 사용한다. 허구의 로그·메신저 UI를 실제 증거로 생성하지 않는다. 시간 절감률·만족도·자동 근본원인 분석·장애 복구는 현재 확인 내용에 포함되지 않는다.

## 5. 필요한 원본과 디자인

현재 내부 원본은 미제공이다. 수집 목록의 상세 요청은 `docs/03-facts-and-assets.md`에 있다. 아래 IMG 번호로 원본을 전달하고, 후보별 화면에 매칭한다.

| 우선순위 | 원본 | 활용 |
| --- | --- | --- |
| 공통 | IMG14 회사 인트로·아웃트로, KV·폰트 | 정확한 5초씩의 고정 영상과 전체 디자인 |
| 후보 4종 | IMG02·IMG03 세미나, IMG04·IMG05 Job Fair, IMG11·IMG12 명장 투어, IMG07 Tech X | 후보 카드·두 방식의 차이·실제 교류 사진 |
| 대표 사례 | IMG08 IAP 로그 감지·메신저 알림, IMG09 소개, IMG10 실습 | 한 장·40초의 실제 기능과 다시 공유 |
| 보조 | IMG06 DCIS, IMG13 교육 플랫폼 | 필요할 때 정기 공유·지식 자산화 설명 |

실제 IAP 화면은 계정·서버명·IP·내부 URL·수신자·운영 데이터 등 공개할 수 없는 항목을 가린 원본으로 받는다. 실제 시설·현장 사진은 사용 가능한 내부 원본을 받는다. 자료가 없으면 후보명·활동 방식·확인 수치를 보여 주는 도식으로 이어간다.

후보 카드·키워드는 회사 KV에 맞춰 리디자인할 수 있다. 대진표와 IAP 도식은 그대로 활용할 수 있도록 원본에서 후보명·선의 방향·글자 크기·대비를 정리한다. 실제 숫자는 참여 규모이며 개선율·순위 점수로 바꾸지 않는다. 최종 영상에서 IMG 코드·원본 요청 문구·검토용 표시를 제거한다.

## 6. 촬영 전 확인과 리허설

1. **출연자 의견:** 공통 질문을 이해하고 각 선택 이유를 자연스럽게 말할 수 있는지 확인. 결과가 달라지면 결승 후보·진출선·마지막 선택까지 동시 수정.
2. **자료와 큐:** 후보 순서·자료 번호·사진·대본·발표자 노트 일치, IAP 한 장·40초 유지, 기존본과 파일 혼용 여부 확인.
3. **실제 발화 시간:** 장면별로 읽고 월드컵 전용 `rehearsal.csv`에 초·메모 기록. 발화자 교대·짧은 반응·선택 호흡을 포함. 추정 보고서는 실측 결과로 대체해 판단.
4. **초과 시 압축:** 먼저 반복되는 후보 설명·과장된 선택 반응·불필요한 전환을 줄인다. 공통 질문·교류의 차이·실제 사례·선택 이유는 보존. 수정 후 275초·300초를 다시 계산.
5. **사실 최신성:** Tech X 6개·44명, Job Fair 11개 부서, 투어 8명, IAP 실습 25명 의미 확인. 10월 OutSystems는 현재 미개최·촬영 전 예정이며 실제 개최 확인 후 자료 상태 수정.
6. **최종 출력:** 원본 수급·가림 처리·회사 KV 적용 후 렌더와 검수 실행. 실제 파일 열람·검수 결과·남은 확인을 보고서에 기록하며 실행 전 성공으로 표시하지 않음.

완료된 검토용 제작 패키지와 내부 원본 확보·리허설 완료·전문 촬영·최종 편집 완료는 구분해서 기록한다. 이 추가 버전은 기존본과 함께 보존한다.
